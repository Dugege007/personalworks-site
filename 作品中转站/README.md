# 作品中转站

投放箱。文件夹统一为 **「中文（技术键）」**：中文对应冻结表 `zh`，并与 `Docs/页面模块` 栏目文件夹对应；括号内是冻结表 `key`（路由 / COS / `placeholders`）。不加文档序号。

入库时按括号里的键**复制**到 `PersonalSite/public/placeholders/{key}/{id}/`，并登记对象台账；不移动、不删除本目录文件。是否已上页以台账与内容层 `src` 为准，不以本目录是否留有文件为准。

本目录是站点本地资源的登记源与长期投放树。`sitemedia` 入库与下架只增不减。补充文件仅人工放入。未上页废图可由本机「网站资源编辑工具」移入回收站；已上页与 `{key}/stock/` 拒绝。站点是否使用某文件，以台账 `published` 与内容层 `src` 为准。同一中转站路径在已上页时只能登记给一个正式位对象；同一正式位对象给多条作品用时，正式位只留一份。下架与再用见 `Docs/工具开发/站点媒体生命周期.md`。

| 中转站 | 入库后 |
|--------|--------|
| `作品中转站/数字孪生（digital-twin）/{id}/` | `public/placeholders/digital-twin/{id}/` |

本目录可放待上页原图、主流视频源片、WebGL 发布包。上页时由网站资源编辑工具压成网页规格，原片保留；正式位只收成片。RAW、PSD、剪辑工程、Unity 工程不要放进本目录。视频上页前压成网页 MP4 与伴生封面，须本机已有 MediaCoder 命令行或 FFmpeg。

`{id}` / `{slug}` 用稳定英文或拼音短名，发布后不改。游戏可把 `游戏开发（game-dev）/_id/` 改名为真实 id。

新增门类时：先在冻结表登记 `zh` / `en` / `deco` / `key`，再同时建 `中文（key）/` 与 `public/placeholders/{key}/`，不得占用 `render`、`construction` 等通用词。

建议文件名：封面 `cover.webp`；详情 `01.webp`、`02.webp`；视频用主流封装（`.mp4` 等），网页成片规格见 `00B` C3 与 `Docs/工具开发/网站资源编辑工具/视频素材整理.md`。

无待入库自有网图时，站点预览可用 `00A` 3.8 图片素材站写入 `placeholders`，并把**该照片页** URL 写入 `Docs/参考资料/来路登记.md`（禁止站首页）；本目录只收自有网图、主流视频源片与 WebGL 包，不把素材站下载件当中转站存货。

## 取用约定

1. 将待发布文件人工放入上表中文文件夹（可保留公司/项目等子目录，或另建 `{id}`）。
2. 对话里给出路径。
3. 按括号内的键**复制**到 `placeholders`，写入内容层 `src` 与对象台账；中转站文件保留。
4. 下架只改正式位（`placeholders` / COS）与内容层，不把网图移回本目录，也不删本目录文件。
5. 再用：本目录仍有该相对路径则直接入库；缺失时人工放回后再执行第 3 步。

未授权人像、未脱敏景观施工图不得投放。
版本库只收一级目录和少量示例夹的空骨架，不收媒体，不收 `术语.txt`。未上页废图不要手删；用网站资源编辑工具标记回收。
