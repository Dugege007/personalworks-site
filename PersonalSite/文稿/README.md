# 网页文稿

本目录只放**站点会读进页面的 Markdown 正本**。改这里、保存后，本地预览会热更新。

不要把设计方案、版本记录、来路登记放进来。那些仍在 `Docs/`。

| 文件 | 对应页面 | 解析 |
|------|----------|------|
| `resume.md` | 简历 `/profile-resume` | `src/content/resume.ts` |
| `skills.md` | 技能 `/profile-skills` | `src/content/skills.ts` |
| `glossary.md` | 名词注解（导语、描述、说明） | `src/content/glossary.ts` |

名词表怎么加、怎么删，见下文「名词说明」。其它页独有字段仍写在该 md 开头。

新增同类文稿：先在本表加一行，再写 md，再在 `src/content` 接解析。字段名可以页自定；切开章节、读「键：值」、列表和加粗走共用读取（`src/content/pageMd.ts`）。规则可随后续页面一起改，改前先改本 README 再改代码。

## 书写（各页共用）

- 正本中文。英文另写在「英文…」字段，不要另开一份英文文件。
- 文件名用页面对应英文（如 `resume.md`、`skills.md`），与解析文件同名；不要用路由键当文件名。
- `#` 一行标题给人看；站点从第一个 `##` 开始读。`#` 下面、第一个 `##` 之前的说明不进页面。
- `##` 是大块（简介、经历、页眉、技能、语言、工具、笔记）。`###` 是块内一条（一段经历、一个工具）。简历 `## 技能` 下的 `###` 是方向，可写可不写。写了按方向分组；不写时，以 `- ` 开头的能力描述仍整句显示，句内顿号不拆开。没有 `- ` 时才按顿号、逗号拆成短名。找不到 `## 技能` 时回退 `## 工具`。简历博客外链写在 `## 笔记`。
- 字段写成 `中文键：值`，全角或半角冒号都行。键不要有空格。某行留空则页面不显示该字段。
- 可跨行的字段目前只有：`说明`、`英文说明`、`描述`、`英文描述`、`笔记`。下一行若仍不是「键：值」，就接到上一字段后面。名词表的 `解释`、`英文解释` 同样可跨行，见下文。
- 短列用 `- ` 或一行里顿号、逗号分开（以该页说明为准）。
- 加粗用 `**这样**`。不要用原生 HTML。简历说明里的链接写成 `[文字](/站内路径)`，页面上为蓝色加下划线。没有地址的 `[文字]` 仍照原样显示。技能栏里单独成行的 `[文字](地址)` 排在条目之后，写法相同。
- 普通句子不要写成「短词：后文」，以免被当成字段。
- 姓名、身份、电话、邮箱不写在本目录，走站点形象。
- 缺字段不补假数据。新领域或新栏目键须先冻结，再写进文稿。

各页独有字段（如履历的 `折叠`、技能的 `官网`）写在该 md 开头或对应设计分册，不塞进本页的共用表。

## 读取（各页共用）

实现：`PersonalSite/src/content/pageMd.ts`。各页只解释本页字段，不重写切开与加粗。

- 按 `##` / `###` 切块；找不到的块当空，不报错、不渲染。
- `键：值` 收进字段表；不认识的键先收着，该页不用则丢弃。
- `是` / `true` / `1` 当作开。未写或 `否` 当作关。
- `**加粗**` 收成可渲染片段，其它标记仍作原文。
- 解析失败的一条跳过，不影响同页其余条目。

## 名词说明

正本是 `glossary.md`。保存后本地预览会热更新。名词出现在导语、项目描述、资源描述、简历简介与说明、技能页眉导语、首页形象导语里。标题、导航、资源名、已经是链接的文字不标。整张卡片本身是链接时，卡里的摘要不标。

技能页上的软件名另走整词对照：中文名或英文名对上名词表，就用名词表的解释、链接和图，名称保持技能页原字重。对不上才用 `skills.md` 的「描述」。熟练度条不读名词表。正文里命中的名词加粗，不加下划线。

`##` 是分组，可以写多组，组名不进页面、不参与匹配。在分组下新增 `###` 即为一条。空的 `别名`、`英文解释`、`图片` 可整行不写。

```markdown
### SketchUp

别名：草图大师
解释：三维建模软件。详见 [SketchUp 官网](https://www.sketchup.com/)。
英文解释：
图片：
```

- `###` 标题是主匹配词。`别名` 用顿号或逗号分开。
- `解释` 必填，未写则整条不收录。`英文解释` 可不写；英文界面没有这段时仍显示中文解释。这两栏的下一行若不是「键：值」，就接到本栏后面。
- 链接写成 `[文字](地址)`。站内地址以 `/` 开头。加粗仍用 `**这样**`。
- `图片` 只写文件名，文件放在 `public/glossary/`，显示高度 96px。自有小图不进中转站，不走作品入库。从网上取的图，先把该素材自己的页面记入 `Docs/参考资料/来路登记.md`。
- 匹配词至少 2 个字符。同一个词写两次时，只用文稿里靠前的一条。纯英文区分大小写，不会标进更长的英文单词。长短词叠在一起时只标长的。
- 删掉一条：删掉对应的 `###` 块后保存。
