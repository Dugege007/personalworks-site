## 3D 引擎

### Unity 3D

别名：Unity
解释：实时 3D 引擎。数字孪生和游戏都可用此引擎开发，使用 C# 编写脚本。[查看官网](https://unity.com)。
英文解释：Realtime 3D engine. Digital twins and games can both be built with it, with scripts written in C#. [View site](https://unity.com).

### 团结引擎

解释：Unity 的中国特供版（Unity 2022 版本的分支），适用于在国内开发 Unity 项目。[查看官网](https://unity.cn/tuanjie/tuanjieyinqing)。
英文解释：Unity's China-specific edition, a branch of Unity 2022. For developing Unity projects in China. [View site](https://unity.cn/tuanjie/tuanjieyinqing).

### Universal Render Pipeline

别名：通用渲染管线、URP
解释：Unity 中的通用渲染管线。[查看文档](https://docs.unity3d.com/Manual/urp/urp-introduction.html)。
英文解释：The Universal Render Pipeline in Unity. [View docs](https://docs.unity3d.com/Manual/urp/urp-introduction.html).

### Input System

别名：InputSystem
解释：Unity 中的新输入系统（旧为 Input Manager），可设置鼠标、键盘、控制器、触控等相关功能。[查看文档](https://docs.unity3d.com/Manual/com.unity.inputsystem.html)。
英文解释：Unity's newer input system. The older one is the Input Manager. It can be set up for mouse, keyboard, controller, and touch. [View docs](https://docs.unity3d.com/Manual/com.unity.inputsystem.html).

### UGUI

解释：Unity 中的 UI 系统。[查看文档](https://docs.unity3d.com/Manual/UISystem.html)。
英文解释：Unity's UI system, uGUI. [View docs](https://docs.unity3d.com/Manual/UISystem.html).

### Cinemachine

解释：Unity 中的相机控制工具，方便制作场景漫游、视角调度。[查看文档](https://docs.unity3d.com/Manual/com.unity.cinemachine.html)。
英文解释：A Unity camera tool for scene walkthroughs and moving the viewpoint. [View docs](https://docs.unity3d.com/Manual/com.unity.cinemachine.html).

### NavMesh

解释：Unity 中的导航工具，方便进行物体的自动寻路。[查看文档](https://docs.unity3d.com/Manual/com.unity.ai.navigation.html)。
英文解释：Unity's navigation tool for automatic pathfinding. [View docs](https://docs.unity3d.com/Manual/com.unity.ai.navigation.html).

### Splines

解释：一款 Unity 插件，可以绘制样条曲线、生成 3D 模型，制作轨道动画。[查看文档](https://docs.unity3d.com/Manual/com.unity.splines.html)。
英文解释：A Unity package for drawing splines, generating 3D meshes, and animating objects along a path. [View docs](https://docs.unity3d.com/Manual/com.unity.splines.html).

### Unity Render Streaming

别名：Unity 渲染流
解释：开源的 Unity 推流工具，可实现远程操控、投屏等功能。[查看文档](https://github.com/Unity-Technologies/UnityRenderStreaming)。
英文解释：An open-source Unity streaming tool for remote control and casting the view to another screen. [View docs](https://github.com/Unity-Technologies/UnityRenderStreaming).

### WebPontis

解释：一款 Unity 插件，用来在网页和 Unity 程序之间传消息。[查看官网](https://ievo.games/)。
英文解释：A Unity plugin for passing messages between a web page and a Unity application. [View site](https://ievo.games/).

### QFramework

解释：Unity 开发框架与工具包，可以在 Unity 中快速实现常用功能。[查看官网](https://qframework.cn/qf)。
英文解释：A Unity framework and toolkit for quickly building common features. [View site](https://qframework.cn/qf).

### DOTween

解释：一款 Unity 插件，可以在 Unity 中快速实现 UI 动画。[查看官网](https://dotween.demigiant.com/)。
英文解释：A Unity plugin for quickly making UI animation. [View site](https://dotween.demigiant.com/).

### A* Pathfinding Project

别名：A* Pathfinding
解释：一款 Unity 插件，可以在 Unity 中实现高级的自动寻路功能。[查看官网](https://arongranberg.com/astar/)。
英文解释：A Unity plugin for advanced automatic pathfinding. [View site](https://arongranberg.com/astar/).

### Chart And Graph

解释：一款 Unity 插件，拥有多种图表工具，配置灵活。[查看官网](https://bitsplash.io/graph-and-chart)。
英文解释：A Unity plugin with several chart tools and flexible setup. [View site](https://bitsplash.io/graph-and-chart).


### Unreal

别名：虚幻引擎、虚幻、UE
解释：Epic Games 的实时三维引擎，常与 Unity 并列，用于游戏和数字孪生场景。脚本主要用 C++ 和蓝图。[查看官网](https://www.unrealengine.com)。
英文解释：Epic Games' realtime 3D engine, often listed alongside Unity, for games and digital-twin scenes. Scripting is mainly C++ and Blueprints. [View site](https://www.unrealengine.com).

## 网络

### Web Graphics Library

别名：WebGL
解释：是一种 3D 绘图协议，也是 Web 的 3D 绘图标准。想在网页打开 Unity 程序，需要将 Unity 打 WebGL 包。[查看文档](https://www.khronos.org/webgl/)。
英文解释：A low-level 3D graphics API, and the web standard for drawing 3D in the browser. Opening a Unity program on a web page means building a WebGL package. [View docs](https://www.khronos.org/webgl/).

### Three.js

别名：three.js
解释：浏览器网页的 3D 库，可以用来做数字孪生场景和网页上的交互。[查看文档](https://threejs.org)。
英文解释：A 3D library for web pages, usable for digital-twin scenes and in-page interaction. [View docs](https://threejs.org).

### HTTP

解释：超文本传输协议。用来向服务器请求数据。[查看文档](https://developer.mozilla.org/en-US/docs/Web/HTTP)。
英文解释：Hypertext Transfer Protocol. Used to request device and work-order data from a server. [View docs](https://developer.mozilla.org/en-US/docs/Web/HTTP).

### Web Socket

别名：WebSocket
解释：在一条连接上双向传数据。可用于 Unity 场景中的设备状态数据拉取。[查看文档](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API)。
英文解释：Sends data both ways over one connection. When device status changes, it is pushed into the 3D scene without refreshing the page. [View docs](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API).

### MQTT

解释：轻量的发布/订阅协议，常用来传设备和传感器的消息。[查看官网](https://mqtt.org/)。
英文解释：A lightweight publish/subscribe protocol, often used to carry messages from devices and sensors. [View site](https://mqtt.org/).

### InfluxDB

解释：开源时序数据库。可以将设备的详细过程参数按时间从其接口取出。[查看官网](https://www.influxdata.com/)。
英文解释：A time-series database. Process values, such as injection-molding parameters, are read from its API over time. The program does not connect to the database directly. [View site](https://www.influxdata.com/).

### WebRTC

解释：实时通讯技术，可以建立浏览器之间点对点（Peer-to-Peer）的连接，实现视频流、音频流等数据的传输。[查看官网](https://webrtc.org/)。
英文解释：A real-time communication technology. It can open a peer-to-peer connection between browsers and carry video, audio, and other data. [View site](https://webrtc.org/).

### 点云

英文解释：A set of discrete points in 3D space. Each point has coordinates, and some also carry color or return intensity. Usually captured by laser scanning or photogrammetry, and used to reconstruct objects and scenes. [View entry](https://zh.wikipedia.org/wiki/%E9%BB%9E%E9%9B%B2).
