# FABRIK 逆运动学

## 是什么

**FABRIK（Forward And Backward Reaching Inverse Kinematics）** 是 Aristidou & Lasenby（2011）提出的启发式逆运动学求解器：给定一根固定骨长的关节链与末端目标位置，迭代调整各关节的**笛卡尔坐标**，使末端尽量落到目标上。它不显式求解关节转角，也不组雅可比矩阵；每一步只做「在两点连成的线段上，按给定骨长取一点」。

逆运动学（IK）本身问的是：已知末端想去哪，反求整条链的位姿。CCD 一类方法按关节逐个转角去追目标；数值 IK 常线性化雅可比再迭代。FABRIK 走的是另一条路——直接改关节位置，骨长由「线段取点」自动保持——因此单轮计算轻、实现短，并已被 Unity Animation Rigging 的 Chain IK、若干游戏引擎与 Final IK 等插件采用。

## 怎么工作

### 直觉画面

把机械臂想成一串用定长杆铰在一起的珠子，根珠焊在基座上。目标出现在可达范围内时：先抓住最末端那颗珠，硬拽到目标点上；再从末端往根走，每一颗珠都必须落在「与下一颗相距恰好等于该节骨长」的球面上——实现上就是沿「当前珠 → 已放好的下一颗」方向量一段骨长。这样走到根时，根珠往往被拽离了基座。于是再反过来：把根珠钉回基座，从根往末端推，每一节同样按骨长前推。一来一回算一轮；末端还没够近就再来一轮，直到误差小于容差或达到最大迭代次数。

目标远在总骨长之外时，再怎么弯也够不着。论文的标准处理是：整条链沿「根 → 目标」方向拉成一条直线，末端停在半径等于总骨长的球面上，朝向目标——演示里就是 **(3.4, 0)** 对准 **(5, 0)**。

### 形式定义（挂回直觉）

记关节位置 \(p_0,p_1,\ldots,p_n\in\mathbb{R}^d\)（本文 \(d=2\)），第 \(i\) 节骨长 \(d_i=\|p_{i+1}-p_i\|\) 在整段求解中保持不变，根 \(p_0\) 固定为 \(r\)，目标为 \(t\)。先算

\[
dist = \|t - r\|,\qquad L=\sum_{i=0}^{n-1}d_i.
\]

若 \(dist \ge L\)（不可达），令单位方向 \(u=(t-r)/dist\)，置

\[
p_0=r,\qquad p_{i+1}=p_i+d_i\,u\quad(i=0,\ldots,n-1),
\]

然后结束。

若 \(dist < L\)（可达），重复下列一轮，直到 \(\|p_n-t\|<\varepsilon\) 或达到最大迭代次数：

1. **Backward（末端→根）**：先令 \(p_n\leftarrow t\)；对 \(i=n-1,\ldots,0\)，

\[
p_i \leftarrow p_{i+1} + d_i\cdot\frac{p_i-p_{i+1}}{\|p_i-p_{i+1}\|}.
\]

2. **Forward（根→末端）**：先令 \(p_0\leftarrow r\)；对 \(i=0,\ldots,n-1\)，

\[
p_{i+1} \leftarrow p_i + d_i\cdot\frac{p_{i+1}-p_i}{\|p_{i+1}-p_i\|}.
\]

「在线段上取点」对应上式：已知已固定的一端与骨长，沿指向另一端（或当前猜测）的方向截一段定长。CCD 是逐关节转角；FABRIK 是直接改位置——对照只需记住这一句。

### 可核对的小例子

设定：SEED=**42**；骨长 **[1.0, 1.0, 0.8, 0.6]**（\(L=3.4\)）；根 **(0,0)**；容差 \(\varepsilon=10^{-6}\)，最大迭代 **32**。初态由同一种子生成折线姿态后按骨长重投影，末端约 **(2.288056, 2.044140)**。

| 情形 | 目标 | \(\|t-r\|\) | 初末端误差 | 终末端误差 | 迭代 | 说明 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| A 可达 | **(2.2, 1.5)** | **2.662705** | **0.5512187768** | **1.540254×10⁻⁷** | **6** | 误差降约六个数量级 |
| B 不可达 | **(5.0, 0.0)** | **5.0** | **3.396049** | **1.6000000000** | **0**（伸直） | 终末端 **(3.4, 0)**，间隙 \(=5.0-3.4\) |

可达情形下，终态各节骨长仍精确为 **1.0／1.0／0.8／0.6**（浮点噪声在 \(10^{-16}\) 量级）。不可达情形不进入迭代循环，直接伸直；终末端到目标距离与 \(dist-L\) 一致。演示图左栏灰线为初态、蓝线为终态、红叉为目标；右栏蓝线为伸直链，虚线圆半径等于总骨长。

## 复杂度和代价

- **单轮**：Backward 与 Forward 各扫一遍 \(n\) 个关节，\(O(n)\)；无矩阵分解、无转角三角函数堆叠（实现里只需归一化方向向量）。
- **迭代次数**：吸引域内常个位数收敛；本例可达目标 **6** 轮到 \(10^{-6}\) 容差。关节很多或初态与目标差得很远时，需要更大 `max_iters` 或更好的初值。
- **与 CCD／雅可比**：CCD 每关节一次旋转，链很长时末端抖动与收敛变慢更常见；雅可比法便于加约束与阻尼，但要组矩阵与求伪逆。FABRIK 适合「位置优先、要快、要稳」的实时链；需要严格关节限位时，论文后续扩展与 Unity Chain IK 的权重／容差参数是工程入口。
- **多末端／分支**：原论文与 2016 扩展讨论多效应器与约束；本篇演示只覆盖单链位置 IK。

## 应用场景

- **数字孪生机械臂**：产线拾取点、放置点在孪生里拖动时，实时解出连杆姿态，供可视化或与实机指令对照。
- **Unity／游戏角色**：手臂、触手、工具指向；Animation Rigging 的 Chain IK Constraint 即 FABRIK 实现。
- **摄像臂／云台连杆**：给定镜头目标点，反推中间铰链位置做预览。
- **可穿戴／动作捕捉后处理**：在骨长约束下把末端钉到标记点，修正漂移。
- **教学与原型**：比雅可比更容易手写验证；先在 2D 核对误差与伸直行为，再接到 3D。

## 实例一：数字孪生／产线机械臂拾取

四轴平面臂总长 3.4（单位米或归一化节长均可）。孪生里把抓取目标设在工作台可达区 **(2.2, 1.5)**：FABRIK 从当前折线姿态出发，**6** 步后末端误差低于 \(10^{-6}\)，各节长度不变，可直接把关节坐标写成控制器的笛卡尔路点或再由几何转成关节角。若操作员误把目标拖到 **(5, 0)**（超出工作半径），求解器不会空转迭代，而是伸直并报告剩余间隙 **1.6**——孪生 UI 可据此标红「不可达」而不是画出穿过限位的弯折。骨长、容差、最大迭代与本文脚本一致时，数字应对得上。

## 实例二：Unity 角色手臂／工具指向

角色肩膀为根、手腕为末端，中间肘与前臂关节构成短链。把「手持焊枪对准零件特征」做成目标 Transform 后，Chain IK（FABRIK）在动画 Rig 层每帧求解：Max Iterations 与 Tolerance 对应本文的 `max_iters`／`tol`。可达时手腕贴目标；角色走开导致目标超出臂长时，手臂伸直指向目标，避免 CCD 式在奇异附近来回拧。需要更强关节锥限制时，再叠 Animation Rigging 的其他约束或 Final IK 的受限 FABRIK；位置求解骨架仍是 Backward／Forward 两趟。

## 短代码（调用核对）

```python
import numpy as np

def fabrik(joints, lengths, target, root, tol=1e-6, max_iters=32):
    p = joints.copy()
    n = len(lengths)
    total = float(lengths.sum())
    dist = float(np.linalg.norm(target - root))
    if dist >= total:  # unreachable: stretch
        u = (target - root) / dist
        p[0] = root
        for i in range(n):
            p[i + 1] = p[i] + lengths[i] * u
        return p, 0
    for it in range(1, max_iters + 1):
        p[-1] = target
        for i in range(n - 1, -1, -1):  # backward
            u = p[i] - p[i + 1]
            p[i] = p[i + 1] + lengths[i] * u / np.linalg.norm(u)
        p[0] = root
        for i in range(n):  # forward
            u = p[i + 1] - p[i]
            p[i + 1] = p[i] + lengths[i] * u / np.linalg.norm(u)
        if np.linalg.norm(p[-1] - target) < tol:
            return p, it
    return p, max_iters
```

## 局限和要注意的地方

1. **本文只解位置。** 末端朝向（旋转）未纳入；需要工具姿态时要另加末端旋转约束或改用带朝向的 IK。
2. **关节限位未建模。** 纯 FABRIK 可能给出「骨长对、角度越界」的姿态；生产臂必须叠关节角范围或论文扩展中的约束投影。
3. **不可达只有伸直策略。** 演示采用论文默认「整链朝目标拉直」；若希望停在工作空间边界上的其他姿态（例如贴障碍），需要额外优化或排斥项。
4. **初态影响中间折线。** 末端误差可到容差以内，但肘部弯向哪一侧取决于初值；对称链可能出现左右肘翻转，动画里常需加肘极向量或惯性平滑。
5. **与解析 IK。** 二连杆等有闭式解的机构，解析法更快且唯一性更清晰；FABRIK 的优势在多节、要统一实现、要实时迭代的场景。

## 延伸思考

1. 固定 SEED=42 与骨长，把可达目标沿圆周 \(\|t\|=2.5\) 采样，记录收敛迭代次数分布。
2. 给 Forward／Backward 之后加简单关节角裁剪（例如每节相对转角不超过 \(\pm 120^\circ\)），观察终误差与伸直行为如何变化。
3. 实现一轮 CCD（从末端关节起逐个旋转），在同一初态与目标上对照迭代次数与终误差。
4. 阅读 Unity Chain IK 文档中的 Tolerance／Max Iterations，把包内参数与本文 \(\varepsilon\)、`max_iters` 对齐后，在 Editor 里拖目标复现「可达收敛／不可达伸直」两种观感。
