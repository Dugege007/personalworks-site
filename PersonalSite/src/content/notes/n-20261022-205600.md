仅用比例控制（Kp=1.8）时，带 0.5 s 纯滞后的一阶惯性对象对单位阶跃的稳态输出停在约 0.64，稳态误差约 0.36；加上积分后误差掉到千分位，但超调升到约 23%；再加带一阶滤波的微分后，超调大约腰斩到约 12%。读完本文可以按 SEED=42 复现脚本，弄清并联型 PID 三项各自在改什么、离散化与抗饱和怎么落地，以及 Ziegler–Nichols 终极增益粗调表给出的数量级关系。

## 是什么

反馈控制要回答的问题很具体：给定设定值 \(r\)，根据测量到的输出 \(y\) 算出执行器指令 \(u\)，使 \(y\) 跟上 \(r\)。产线温控里 \(r\) 是目标温度、\(u\) 是加热功率；输送带速度环里 \(r\) 是目标线速度、\(u\) 是变频器频率给定。对象往往可以先用**一阶惯性加纯滞后（first-order plus dead time, FOPDT）**近似：

\[
\tau\,\dot y(t)=-y(t)+K\,u(t-L),
\]

其中 \(K\) 是稳态增益，\(\tau\) 是时间常数，\(L\) 是运输或传感造成的纯滞后。

**PID（Proportional–Integral–Derivative，比例–积分–微分）**是把误差 \(e=r-y\) 的「现在、累积、变化率」三路信息合成控制量的经典结构。本文采用工业里常见的**并联型（parallel form）**写法：

\[
u(t)=K_p\,e(t)+K_i\int_0^t e(\sigma)\,d\sigma+K_d\,\dot e(t).
\]

与理想型／标准型 \(u=K_p\bigl(e+\frac{1}{T_i}\int e+T_d\dot e\bigr)\) 的对应关系是 \(K_i=K_p/T_i\)、\(K_d=K_p T_d\)（\(T_i\) 为积分时间，\(T_d\) 为微分时间）。Åström 与 Murray 的 *Feedback Systems*、以及 Åström 与 Hägglund 关于 PID 的教材，都把这种三项分解当作入门与调参的主叙事；下文离散实现、滤波与抗饱和也按同一并联口径叙述。

J. G. Ziegler 与 N. B. Nichols 在 1942 年 *Transactions of the ASME* 的论文 *Optimum Settings for Automatic Controllers* 里给出了基于**终极增益 \(K_u\)**与**振荡周期 \(T_u\)**的粗调表。对 PID，常用并联增益形式为

\[
K_p=0.6\,K_u,\qquad K_i=1.2\,\frac{K_u}{T_u},\qquad K_d=0.075\,K_u\,T_u,
\]

等价于 \(T_i=T_u/2\)、\(T_d=T_u/8\)。该方法先把积分与微分关掉，只加大 \(K_p\) 直到闭环出现等幅振荡，读出 \(K_u\) 与 \(T_u\)，再套表。它是粗起点而不是终点；演示里的三组增益为可复现而写死，数量级关系与「P 有残差、PI 消残差易超调、D 抑超调」的教学故事一致，正文同时给出 Z–N 公式以便对照。

## 怎么工作

### 直觉画面

把加热器想成「房间温度追设定」：

1. **比例 P**：现在偏冷多少，就按比例加大加热。偏得大，出力大；已经贴近时出力变小。它反应快，但对象有有限增益时，往往**留一点静差**——永远差那么一点才够「撑住」负载。
2. **积分 I**：把历史上「一直偏冷」的面积累加起来，哪怕当前误差已经很小，累积项仍会慢慢把加热顶上去，直到静差被抹平。代价是累积过猛时会冲过设定值，形成超调甚至来回晃。
3. **微分 D**：看温度正在升得多快。升得太猛就提前减加热，相当于刹车。它对测量噪声敏感，工程上几乎总会给微分通路加一阶低通。

三路相加（并联），再经执行器饱和限幅，就是一条可上机的 PID。

### 形式定义（挂回直觉）

连续并联型已如上文。数字控制器按采样周期 \(T_s\) 更新。演示采用**位置式**离散化：

- **积分**：后向欧拉（backward Euler）\(I_k=I_{k-1}+K_i T_s e_k\)。
- **微分**：作用在测量 \(y\) 上（避免设定值阶跃时的微分冲击），并加滤波时间常数 \(T_f\approx 0.1\,T_d\)。令 \(T_d=K_d/K_p\)（当 \(K_p>0\)），则

\[
D_k=\frac{T_f}{T_f+T_s}D_{k-1}+\frac{K_d}{T_f+T_s}\bigl(-(y_k-y_{k-1})\bigr).
\]

这对应连续滤波 \(\dfrac{-K_d s}{T_f s+1}Y(s)\) 的后向差分实现。未滤波的纯差分 \(K_d(e_k-e_{k-1})/T_s\) 在噪声下会把 \(u\) 打成毛刺，产线里通常不可用。

- **合成与钳位**：\(u_k^{\mathrm{unsat}}=K_p e_k+I_k+D_k\)，再 \(u_k=\mathrm{clip}(u_k^{\mathrm{unsat}},u_{\min},u_{\max})\)。
- **抗饱和（演示用条件积分）**：若发生饱和，撤销本拍对 \(I_k\) 的更新（积分冻结）。更完整的做法还有 back-calculation（把饱和差额按跟踪时间常数回灌积分器）；演示点到钳位＋冻结即可说明「积分在饱和时不能无脑累加」。

对象侧每拍用零阶保持下的精确离散步推进一阶惯性，纯滞后 \(L\) 用长度为 \(\mathrm{round}(L/T_s)\) 的先进先出缓冲实现。

### 可核对的小例子（演示设定）

参数写死在脚本里（`SEED=42`）：

- 对象：\(K=1.0\)，\(\tau=2.0\,\mathrm{s}\)，\(L=0.5\,\mathrm{s}\)；采样 \(T_s=0.05\,\mathrm{s}\)；仿真到 \(30\,\mathrm{s}\)；\(t=1\,\mathrm{s}\) 时设定值从 0 阶跃到 1。
- 执行器：\(u\in[0,\,3]\)；测量噪声标准差 \(0.004\)（按上述 SEED 分控制器复现）。
- 微分滤波：\(T_f=0.1\,T_d\)，\(T_d=K_d/K_p\)。
- 三组并联增益：

| 控制器 | \(K_p\) | \(K_i\) | \(K_d\) |
|---|---:|---:|---:|
| P | 1.8 | 0 | 0 |
| PI | 1.4 | 1.35 | 0 |
| PID | 1.7 | 1.15 | 0.65 |

对单位负反馈、稳态增益为 \(K\) 的对象，纯 P 的理论稳态误差为 \(e_{\mathrm{ss}}=r/(1+K_p K)\)。代入 \(r=1\)、\(K=1\)、\(K_p=1.8\) 得 \(e_{\mathrm{ss}}\approx 0.357\)，与仿真末 2 s 均值一致。PI／PID 的积分项把该残差赶到噪声量级。

## 复杂度和代价

- **时间／存储**：每拍常数时间更新 \(I\)、\(D\)、钳位；滞后缓冲 \(O(L/T_s)\)。演示约 600 步，普通解释器上毫秒到几十毫秒级。
- **调参代价**：Z–N 需要能安全地逼近等幅振荡；许多产线不允许主动振荡，改用阶跃响应辨识 FOPDT 再套 IMC／λ 整定，或继电器反馈估 \(K_u,T_u\)。表值常偏激进，上线后还要按超调与调节时间微调。
- **噪声与 \(T_f\)**：\(T_f\) 太小则 D 通路仍吵；太大则刹车变钝，超调抑制变弱。\(0.1\,T_d\) 是常见起点。
- **饱和**：大阶跃时 \(u\) 顶满，若积分不冻结，解除饱和后会有明显超调（积分饱和／windup）。钳位必须与某种抗饱和策略一起出现。

## 应用场景

- **产线／数字孪生温控或速度环**：加热区、烘道、浴槽用 FOPDT 做孪生对象；先在模型上对比 P／PI／PID 的超调与调节时间，再把同一组离散式下到 PLC 或嵌入式周期任务。输送带速度跟踪同构：\(L\) 来自通信与机械间隙，\(\tau\) 来自惯量与摩擦等效。
- **电机电流／转速伺服、云台与镜头跟焦**：内环常用 PI，外环或位置环加 D 或超前环节；离散式与抗饱和套路相同。
- **网页或游戏里的相机跟随／弹性动画**：把「目标锚点」当 \(r\)、画面位置当 \(y\)，用 PD 或 PID 代替手写阻尼弹簧，参数可解释为刚度与阻尼。
- **旁例**：电池化成柜温度、温室通风，同样是「慢热对象＋执行器饱和」，PID 仍是第一刀；模型预测控制等多变量方法往往在 PID 搭好底座后再上。

## 实例一：FOPDT 单位阶跃（可复现）

脚本 `code/2026-10-22-pid_fopdt_step.py` 在同一对象上跑通三组控制器。指标定义：稳态误差取仿真末 2 s 输出均值相对设定值的绝对偏差；超调为阶跃后峰值相对设定值的百分比；调节时间为进入并保持在设定值 \(\pm 2\%\)（或 \(\pm 5\%\)）带宽内的时间（自阶跃时刻起算）。

| 项目 | P | PI | PID |
|---|---:|---:|---:|
| \(K_p,\,K_i,\,K_d\) | \(1.8,\,0,\,0\) | \(1.4,\,1.35,\,0\) | \(1.7,\,1.15,\,0.65\) |
| 稳态误差 \(e_{\mathrm{ss}}\) | \(0.356818\) | \(0.001272\) | \(0.000710\) |
| 稳态输出均值 \(y_{\mathrm{ss}}\) | \(0.643182\) | \(1.001272\) | \(0.999290\) |
| 超调 (%) | \(0.000\) | \(22.651\) | \(11.877\) |
| 调节时间 \(\pm 2\%\) (s) | （未进入） | \(7.250\) | \(7.300\) |
| 调节时间 \(\pm 5\%\) (s) | （未进入） | \(4.900\) | \(6.200\) |

读表时注意三点。第一，P 的残差不是实现写错，而是**有限比例增益下闭环直流增益小于 1**；加大 \(K_p\) 可缩小残差，但纯滞后对象上过大 \(K_p\) 会逼近 Z–N 所说的振荡边界。第二，PI 把误差抹平，却付出约 23% 超调。第三，PID 在相近的 \(\pm 2\%\) 调节时间下把超调降到约 12%；\(\pm 5\%\) 带宽上 PI 略快，是因为 PI 冲得更高、更早穿过 5% 带，并不否定 D 项对峰值的抑制。演示图上图为设定值与三条 \(y(t)\)，下图为对应 \(u(t)\)（含上下钳位参考线）。

## 实例二：烘道温度孪生上的同一套离散式

把演示里的 \(y\) 读成「区段中心温度偏差（归一化）」，\(u\) 读成「电热比例阀开度」。辨识得到 \(\tau\approx 2\,\mathrm{s}\) 量级（实验室小通道；真实烘道往往数分钟，只是时间轴缩放）与 \(L\approx 0.5\,\mathrm{s}\) 的传感／气体传输滞后。先在孪生里用脚本同一套后向欧拉＋滤波 D＋条件积分，扫 \(K_p,K_i,K_d\)，看超调是否触碰工艺上限（例如不允许超过设定 15%）。再把 \(T_s\)、增益与 \(T_f\) 写进控制器任务；上线时保留 \(u\) 钳位与积分冻结，避免开门投料后长时间满功率造成的积分饱和。若现场允许继电器测试，可用测得的 \(K_u,T_u\) 套 Z–N 表作初值，再按本演示的指标表做细调。

## 短代码（位置式并联 PID 一拍）

```python
# e = r - y_meas; 积分后向欧拉；D 为对 y 的滤波微分；饱和时撤销本拍积分
I = I + Ki * Ts * e
d_raw = -(y_meas - y_prev)
D = (Tf / (Tf + Ts)) * D + (Kd / (Tf + Ts)) * d_raw
u_unsat = Kp * e + I + D
u = min(max(u_unsat, u_min), u_max)
if u != u_unsat:
    I = I - Ki * Ts * e
y_prev = y_meas
```

## 局限和要注意的地方

1. **FOPDT 只是近似。** 高阶谐振、强非线性阀门、变滞后会使一组固定 PID 在工况大漂移时失配；需要增益调度或改辨识。
2. **Z–N 偏激进。** 表值常带来偏大超调，只适合当初始猜测。
3. **微分必须滤波。** 编码器量化、温度 AD 抖动会放大 D 项；\(T_f\) 与采样周期要一起设计。
4. **设定值加权。** 工业实现常对 P／D 通道使用设定值权重（两自由度 PID），以减少阶跃时的踢动；演示为突出三项对比未展开。
5. **多回路耦合。** 温区之间有热耦合时，单回路 PID 各自为政可能振荡；需要解耦或集中式设计。

## 延伸思考

1. 固定 PI 增益，只扫 \(K_d\) 与 \(T_f/T_d\)，画超调与 \(\pm 2\%\) 调节时间的曲线，观察噪声标准差加大后最优 \(T_f\) 如何右移。
2. 去掉条件积分，只保留 \(u\) 钳位，比较大阶跃下的超调差异，量化积分饱和的代价。
3. 用继电器反馈估计本对象的 \(K_u,T_u\)，代入 Z–N 的 \(K_p=0.6K_u\)、\(K_i=1.2K_u/T_u\)、\(K_d=0.075K_u T_u\)，与文中手调增益对比超调。
4. 将对象改成无纯滞后的纯一阶惯性，重复 P／PI／PID，说明此时 D 项收益变小的原因（相位滞后主要来自 \(L\)）。
