## 是什么

**威布尔分析**用两参数威布尔分布来描述「一件东西第一次失效要等多久」。分布由形状参数 \(\beta>0\)（也常写作 \(\gamma\)）和尺度参数 \(\eta>0\)（特征寿命，也常写作 \(\alpha\)）决定。时刻 \(t>0\) 的可靠度、不可靠度（累积失效概率）和瞬时失效率分别是

\[
R(t)=\exp\left[-\left(\frac{t}{\eta}\right)^{\beta}\right],
\quad
F(t)=1-R(t),
\quad
h(t)=\frac{\beta}{\eta}\left(\frac{t}{\eta}\right)^{\beta-1}.
\]

可靠度 \(R(t)\) 是「寿命超过 \(t\)」的概率；失效率 \(h(t)\) 是「已经活到 \(t\)、再在接下来一瞬间失效」的强度。特征寿命 \(\eta\) 有一个固定读法：\(R(\eta)=e^{-1}\approx 0.3679\)，也就是大约 63.2% 的个体会在 \(\eta\) 之前失效。它一般不等于平均寿命。平均寿命是 \(\eta\,\Gamma(1+1/\beta)\)，其中 \(\Gamma\) 是伽马函数。

这个分布能横跨几种常见的失效节奏，只靠 \(\beta\) 切换：小于 1 时失效率下降（早期失效占主导），等于 1 时退化为指数分布、失效率恒定，大于 1 时失效率上升（耗损失效）。它还可以从极值理论里的「最弱环」推出来：许多潜在缺陷里最先被击穿的那一个，极限分布往往就是威布尔——这有助于理解它为什么常出现在轴承、电容、材料强度这类问题上。Waloddi Weibull 在 1951 年的 ASME 论文里把它作为「适用面很宽的统计分布」提出来；NIST/SEMATECH 工程统计手册第 8 章把它列为不可修产品寿命的基本模型之一。不同文献里 \(\beta\) 和 \(\eta\) 的字母常对调，读公式时要先对一下哪个是形状、哪个是尺度。

**本文范围：** 位置固定为 0 的两参数威布尔、完全样本与右截尾的极大似然估计、B10 寿命与条件可靠度，以及 12 条完全失效时间和 40 台电机定时截尾两组可复现演示。**非范围：** 带保证寿命（位置参数）的三参数威布尔、加速寿命试验、可修系统的威布尔过程、竞争失效机理，以及形状参数的置信区间推导——那些需要单独篇幅。

## 怎么工作

### 形状参数决定失效率上升还是下降

把 \(\eta\) 固定，只改 \(\beta\)，失效率曲线的走向会完全不同。\(\beta<1\) 时，\(h(t)\) 在时间起点附近很高，随后下降：早期的薄弱单元先被淘汰，活下来的反而更稳。\(\beta=1\) 时 \(h(t)=1/\eta\)，是一条水平线，对应「无记忆」的指数寿命。\(\beta>1\) 时 \(h(t)\) 随时间上升，表示磨损、疲劳或老化在累积。装配线上的电机、轴承多半落在最后这一类；如果数据其实是早期失效为主，却强行用大于 1 的形状去外推后期风险，判断就会反过来。

### 特征寿命和 B10 都不是样本平均数

工程里除了 \(\eta\)，还常用 **B10 寿命**：不可靠度到达 10% 的时刻，也就是 \(F(t_{10})=0.10\)。由可靠度公式反解，得到

\[
t_{p}=\eta\left[-\ln(1-p)\right]^{1/\beta},
\]

B10 对应 \(p=0.10\)。它回答的是「先坏掉的那一成大概在什么时候出现」，和「平均要多久才坏」不是同一个问题。

下面用真值 \(\beta=2\)、\(\eta=1000\) 小时做一次手算，便于和脚本对表。先算 \(-\ln(0.9)\approx 0.105361\)，再开平方（因为 \(1/\beta=1/2\)），得到 B10 \(=1000\times 0.324593=324.6\) 小时。500 小时的可靠度是 \(\exp(-(500/1000)^{2})=\exp(-0.25)=0.7788\)，也就是到 500 小时仍有约 77.9% 未失效。平均寿命是 \(1000\times\Gamma(1.5)=1000\times\sqrt{\pi}/2=886.2\) 小时，既不等于 1000，也不等于 324.6。下面这段代码只核对这三项公式，前提是 Python 3 并能导入 NumPy；预期输出为 `324.5928`、`0.778801`、`886.2269`。

```python
import numpy as np
from math import gamma

def reliability(t, eta, beta):
    return np.exp(-((t / eta) ** beta))

def b_life(p, eta, beta):
    return eta * ((-np.log(1.0 - p)) ** (1.0 / beta))

eta, beta = 1000.0, 2.0
print(round(b_life(0.10, eta, beta), 4))
print(round(float(reliability(500, eta, beta)), 6))
print(round(eta * gamma(1.0 + 1.0 / beta), 4))
```

### 用极大似然估计形状和尺度（含右截尾）

\(\beta\) 没有干净的闭式解，要用数值方法最大化对数似然。完全失效时间 \(t_i\) 对似然的贡献是密度 \(f(t_i)\)；只知道「到 \(\tau_j\) 还没坏」的右截尾样本，贡献的是可靠度 \(R(\tau_j)\)。写成对数是

\[
\ell(\beta,\eta)
=\sum_{i\in\text{失效}}\Big[\ln\beta-\ln\eta+(\beta-1)\ln(t_i/\eta)-(t_i/\eta)^{\beta}\Big]
-\sum_{j\in\text{截尾}}(\tau_j/\eta)^{\beta}.
\]

实践中在 \((\ln\beta,\ln\eta)\) 坐标里做无约束极小化（负对数似然），可以避免参数跑出正实数范围。SciPy 的 `weibull_min.fit(..., floc=0)` 对完全样本直接适用；有右截尾时，把数据包成 `CensoredData` 再交给同一个 `fit`。下面是负对数似然的核心，省略了优化器调用；完整拟合、对照 SciPy 与出图见交付包脚本。

```python
import numpy as np

def weibull_nll(theta, times, failed):
    # theta = (ln beta, ln eta)；failed 为 True 表示该时刻观测到失效
    beta, eta = np.exp(theta[0]), np.exp(theta[1])
    z = (times / eta) ** beta
    log_f = np.log(beta) - np.log(eta) + (beta - 1.0) * np.log(times / eta) - z
    log_r = -z
    return float(-np.sum(np.where(failed, log_f, log_r)))
```

位置参数被固定为 0，含义是「从投入运行起就进入风险」，不再额外估计一段保证寿命。若物理上确定存在不会失效的前期，应先平移时间轴，再回到两参数估计，而不是把 `floc` 放开让优化器随便移动原点。

### 可核对的玩具：12 条完全失效时间

用 \(\beta=2\)、\(\eta=1000\) 小时生成 12 条完全失效时间，四舍五入到整小时（种子 42）：

265、282、294、529、1023、1044、1187、1205、1528、1544、1551、1768。

样本平均数是 **1018.3** 小时。自写极大似然得到 \(\hat\beta=2.013\)、\(\hat\eta=1147.5\) 小时，B10 为 **375.3** 小时，平均寿命估计为 **1016.8** 小时；同一批数交给 SciPy，结果为 2.014 与 1147.5 小时，在文中使用的小数位上可以看成一致。形状估得很近，特征寿命和 B10 都比真值偏大：12 条完全样本还不够把尺度钉死，这是小样本的正常波动，不是公式写错。

画威布尔概率纸时，常用 Bernard 中位秩 \(F_i=(i-0.3)/(n+0.4)\) 作为横轴概率位置，再点 \((\ln t_i,\ \ln(-\ln(1-F_i)))\)。若数据大致服从威布尔，这些点应近似落在一条直线上，斜率就是 \(\beta\)。第一条可以手算：\(i=1\) 时 \(F=(1-0.3)/(12+0.4)=0.7/12.4=0.056452\)，对应 \(t=265\)，\(\ln t=5.579730\)，\(\ln(-\ln(1-F))=-2.845458\)。12 个点整体接近直线，中间有一段空隙（529 小时之后跳到 1023 小时），所以拟合直线与真值直线接近但不重合。

## 复杂度和代价

- **计算量：** 单次负对数似然是 \(O(n)\)。两参数的数值极大似然对几十到几千条寿命记录都很快；耗时通常花在把失效时间和截尾时间登记清楚，而不是这几次优化迭代。
- **样本与截尾：** NIST 手册的经验是，至少观察到大约 10 次确切失效，形状参数的估计才比较稳；少于 5 次失效时估计常常很不准。截尾比例高时，后期可靠度更依赖模型外推，而不只是已经看见的失效点。
- **无视截尾的偏差：** 把还在运行的个体丢掉、只对失效时间取平均，等于系统性地丢掉「活得更长」的证据，平均寿命会被低估。
- **模型风险：** 概率纸明显弯曲时，应怀疑威布尔是否合适，常见对照是对数正态。形状估错时，短时 B10 可能仍看起来不错，但「再支撑一段时间」的条件概率会偏得更厉害，因为那一段落在曲线更靠后的位置。
- **参数补偿：** \(\beta\) 偏高、\(\eta\) 偏低（或相反）时，某个分位点（例如 B10）可能几乎重合，并不代表整条可靠度曲线都估准了。

## 应用场景

两参数威布尔常见于不可修部件的首次失效：轴承、电容、继电器，以及材料强度里的最弱环。数字孪生车间可以用已经观测到的失效时间和仍在运行的累计台时，更新同一型号的寿命模型，再把 B10、某次计划停机前的失效概率，送到备件与检修窗口里。关键输入是条件可靠度

\[
R(t+\Delta t\mid t)=\frac{R(t+\Delta t)}{R(t)}=\exp\left[-\left(\frac{t+\Delta t}{\eta}\right)^{\beta}+\left(\frac{t}{\eta}\right)^{\beta}\right],
\]

它回答「已经无故障运行了 \(t\) 小时的设备，再撑过 \(\Delta t\) 小时」的概率。\(\beta=1\) 时这个比值等于新设备的 \(R(\Delta t)\)，也就是指数分布的无记忆性；\(\beta>1\) 时，用过的设备再撑过 \(\Delta t\)，通常难于全新设备撑过同样长的 \(\Delta t\)。

### 装配工位上的电机寿命（右截尾）

40 台同型电机从同一起点投入，真值 \(\beta=2.2\)、\(\eta=1600\) 小时，观测在 1500 小时统一截止。四舍五入到整小时后，**26** 台在截止前失效，失效时间为

277、487、499、540、683、707、733、810、833、897、921、947、954、956、985、998、1039、1041、1070、1075、1117、1125、1308、1321、1347、1368；

另外 **14** 台在 1500 小时仍在运行，记为右截尾。只对 26 个失效时间取平均得到 **924.5** 小时，远低于真平均寿命 **1417.0** 小时。带截尾的极大似然给出 \(\hat\beta=2.472\)、\(\hat\eta=1429.4\) 小时，平均寿命估计为 **1268.0** 小时，方向已经纠正，但仍偏低。B10 估计为 **575.1** 小时，和真值 **575.3** 小时几乎重合——这是 \(\beta\) 偏高与 \(\eta\) 偏低互相补偿的结果，不能单独拿来证明整条曲线都估准了。例如 1000 小时可靠度的真值是 0.7008，估计是 0.6613；1500 小时真值是 0.4199，估计是 0.3242，尾部偏差更大。

观测截止时仍在运行的 14 台，再撑 300 小时的条件可靠度，真值是 0.6517，估计是 0.5266。同一模型下，一台全新电机撑过 300 小时的可靠度真值为 0.9752，估计为 0.9791。耗损型形状让「已经跑了 1500 小时」明显难于「刚上线的 300 小时」；拟合曲线把这一差距放得更夸大了一些。作为非参数对照，这 26 次失效之间没有截尾、也没有并列，最后一次失效（1368 小时）处的 Kaplan–Meier 可靠度就是仍在风险集中的台数除以总台数：\(14/40=0.3500\)。它在截止时刻不会自动继续下降，因为 1500 小时处没有新的失效，只有截尾。

## 局限和要注意的地方

1. **小样本和截尾会放大尺度误差。** 玩具 12 条就把特征寿命从 1000 估到了 1147；产线例子里 B10 几乎估准，1500 小时以后的条件概率却偏得更多。
2. **截尾不是缺失值。** 仍在运行的记录必须进似然，不能当失效，也不能直接删掉。
3. **两参数假定风险从 0 时刻开始。** 若存在明确的保证寿命，应先平移再拟合；把位置参数一并自由估计，小样本里很容易不稳定。
4. **可修系统不要直接套首次失效的威布尔。** 「修好再坏」属于更新过程或威布尔过程，参数含义不同。
5. **这是寿命模型，不是故障诊断。** 它给出的是群体的时间风险，并不指出某台电机这次是轴承还是绝缘先坏。

## 延伸思考

1. 把玩具样本的中位秩改成 \(i/(n+1)\)，重画概率纸，看斜率相对 2.013 会偏多少。
