两条长度只有 7 与 6 的短序列 \(x=[1,3,4,9,8,2,1]\)、\(y=[1,6,3,9,1,2]\)，按点对点截断根本对不齐；用平方欧氏局部代价做经典动态时间规整（Dynamic Time Warping，DTW），累计代价矩阵终点恰好是 **12**，开方后的 DTW 距离是 **3.4641016151**（即 \(\sqrt{12}\)），最优路径 8 步，且与一份独立备忘录递推实现逐位一致。把同一套实现接到产线振动周期上：参考周期 80 点、对照周期 95 点并带时间伸缩与噪声（SEED=42），DTW 约 **0.678**，而截断欧氏约 **7.072**、重采样欧氏约 **3.700**——同形态却「慢半拍」时，硬对齐会把相位差当成形状差。读完可以按脚本复现代价矩阵、路径与产线对照数字，弄清边界／单调／连续步进如何约束对齐，以及 Sakoe–Chiba 带宽怎样少填格子仍得到同一距离。

## 是什么

**动态时间规整（DTW）** 是一种序列相似度度量：允许两条曲线在时间轴上局部拉伸或压缩，再累加对齐后的局部代价，取所有合法对齐路径中的最小值。它最初在语音识别里对齐发音快慢不同的同一词（Sakoe & Chiba, 1978），后来在传感器轨迹、手势、设备周期波形对比里反复出现。

和普通欧氏距离不同，DTW **不要求**两条序列等长，也不假设第 \(i\) 个采样必须对第 \(i\) 个采样。它要求的是一条从起点走到终点的**规整路径**：索引只前进、一步最多各走一格，并把沿途局部代价加起来。`tslearn` 等库默认把「路径上平方欧氏之和再开方」记作 DTW 距离；下文数字一律按该约定，便于和文档伪代码对表。

DTW 满足非负与 \(DTW(x,x)=0\)，但一般**不满足三角不等式**，因此它是相似度／伪距离，不是严格度量。聚类、近邻检索里仍可当代价用；需要可微版本时再看 soft-DTW，本文只讲经典硬最小。

## 怎么工作

### 直觉画面

把序列 \(x\) 的下标排成表格的行，\(y\) 的下标排成列。格子 \((i,j)\) 上写「把 \(x_i\) 对齐到 \(y_j\)」的局部代价，常用平方欧氏 \(d(x_i,y_j)^2=(x_i-y_j)^2\)。一条规整路径就是从左上角 \((0,0)\) 走到右下角 \((n-1,m-1)\) 的折线：每一步只能向右、向下或向右下，对应「只推进 \(y\)」「只推进 \(x\)」或「两边一起推进」。折线经过的格子代价相加，总和最小的那条就是最优对齐；总和再开方，便是文中的 DTW 距离。

路径不能往回走（单调），也不能跳格（连续步进），还必须钉死两端（边界条件）。直观上，高峰可以多对一、低谷可以一对该：形状像、节拍略拧的两条曲线，仍可能走出一条贴着「低代价走廊」的折线。

### 形式定义（挂回直觉）

记 \(x=(x_0,\ldots,x_{n-1})\)、\(y=(y_0,\ldots,y_{m-1})\)。合法路径 \(\pi=[(i_0,j_0),\ldots,(i_{K-1},j_{K-1})]\) 满足：

1. **边界**：\((i_0,j_0)=(0,0)\)，\((i_{K-1},j_{K-1})=(n-1,m-1)\)；
2. **单调与连续步进**：对每个 \(k\ge 1\)，\(i_{k-1}\le i_k\le i_{k-1}+1\) 且 \(j_{k-1}\le j_k\le j_{k-1}+1\)（至少一侧前进，实现里由三个前驱保证）。

优化目标（与 `tslearn` 用户指南一致）为

\[
\mathrm{DTW}(x,y)=\min_{\pi}\sqrt{\sum_{(i,j)\in\pi}d(x_i,y_j)^2}.
\]

动态规划填累计代价 \(C\)：

\[
C(i,j)=d(x_i,y_j)^2+\min\bigl\{C(i-1,j-1),\,C(i-1,j),\,C(i,j-1)\bigr\},
\]

边界行／列只允许从一个方向递推；不可达处置 \(+\infty\)。最后 \(\mathrm{DTW}=\sqrt{C(n-1,m-1)}\)，再沿指针回溯得到 \(\pi\)。时间与空间均为 \(O(nm)\)（只存两行时可压到 \(O(\min(n,m))\) 空间，但要路径仍需额外记录）。

**Sakoe–Chiba 带**再加全局窗：只允许 \(|i-j_{\mathrm{mapped}}|\le r\) 附近的格子参与（不等长时把列下标映射到行尺度）。带宽 \(r\) 越小，填格越少、路径越贴对角线，极端时可能逼近「几乎不许扭曲」的对齐。

### 可核对的小例子

对 \(x=[1,3,4,9,8,2,1]\)、\(y=[1,6,3,9,1,2]\)，脚本打印累计矩阵 \(C\) 的终点为 **12.0**，DTW=**3.4641016151**。最优路径为

\[
(0,0)\to(1,0)\to(2,1)\to(2,2)\to(3,3)\to(4,3)\to(5,4)\to(6,5)
\]

共 **8** 步。沿途局部平方代价依次为 \(0+4+4+1+0+1+1+1=12\)，与 \(C[-1,-1]\) 一致；另一份纯递归备忘录实现给出同一开方值，可作为交叉核对。演示图左上把对齐线画在两条折线上，右上是 \(C\) 的热力与青色最优路径。

## 复杂度和代价

- **朴素 DTW**：时间 \(O(nm)\)，完整矩阵空间 \(O(nm)\)。产线例 \(80\times 95=7600\) 格在普通笔记本上瞬时可算。
- **Sakoe–Chiba 半径 \(r\)**：有效格子大约随 \(O((n+m)r)\) 增长。本例 \(r=12\) 时有限格 **2112／7600**（约 **27.8%**），距离仍为 **0.677721**，说明最优路径本身就落在带内；再收窄带才可能抬高距离或使终点不可达。
- **实现陷阱**：局部代价用绝对值还是平方、最后开不开方，会让「同一对序列」在不同库里对不上数字；与 `tslearn.metrics.dtw` 对表时应用平方欧氏并开方。不等长序列的窗约束要用映射后的对角线，不能照搬等长时的 \(|i-j|\le r\) 而不加说明。
- **可扩展性**：上千点周期可先降采样或加带；上万点以上常见做法是限制窗、下界剪枝（LB_Keogh 等）或改用近似 DTW，本文不展开。

## 应用场景

- **数字孪生周期对比**：同一工位相邻若干周期的振动／电流包络，长度常差几个采样点；DTW 比硬截断更适合做「形态是否仍像标准周期」的分数。
- **传感器轨迹对齐**：机械臂或 AGV 示教轨迹与回放轨迹节拍不同，对齐后再比空间误差。
- **语音／手势／波形检索**：模板匹配、关键词检出、异常片段检索的经典底座。
- **预测与前端**：把多条历史负荷曲线对齐后做中位数包络；或在看板里用 DTW 距离给「最像的历史班次」排序。前端可用预计算距离矩阵热力（类似演示图）展示对齐路径，而不必在浏览器里重跑 \(O(nm)\)。

## 实例一：产线振动周期——慢半拍时 DTW 与欧氏的反差

用 SEED=42 生成参考周期 \(n=80\)（标准节拍），再用 SEED+1 生成对照周期 \(m=95\)：中间相位被幂次拉伸（stretch=1.35）并加略大噪声，模拟「同一模具动作却整体慢半拍、采样点更多」。脚本得到：

| 度量 | 数值 |
| --- | ---: |
| DTW（平方欧氏路径，再开方） | **0.677721** |
| 截断到 80 点后的欧氏范数 | **7.072218** |
| 线性重采样到 80 点后的欧氏范数 | **3.700280** |

截断相当于假装后段不存在，相位错位被直接写进残差；重采样统一了长度，但仍按「同一归一化时刻」对齐，扭曲集中在中间时仍偏大。DTW 允许路径在代价矩阵里沿低谷走廊走弯，把慢半拍吸收进时间扭曲，剩余距离主要来自噪声与细形态差。演示图左下是两条归一化时间轴上的波形，右下是 \(80\times 95\) 累计代价与最优路径；路径贴近对角线但明显锯齿，对应局部加速／减速。

## 实例二：工位标准周期库与前端对齐热力

数字孪生里可为每个关键工位存一条「合格标准周期」波形（或一小簇模板）。新采到的周期先做幅度归一，再对模板算 DTW；超过阈值则标「节拍／形态异常」，而不是只看峰值是否越限。Sakoe–Chiba 半径可按工艺拧紧：允许的时间扭曲不超过约 \(r\) 个采样，既加速又避免病理对齐（开头对结尾）。

前端侧不必每次交互重算：边缘采集端算好 \(C\) 与路径后，把矩阵缩略图和路径折线推到看板，访客看到的视觉与演示图右栏同类——深色走廊加一条亮色折线。若只需排序「最像哪几个历史班次」，可只存标量 DTW 与路径长度 \(K\)，热力按需展开。

## 短代码（调用核对）

```python
import numpy as np

def dtw(x, y):
    x, y = np.asarray(x, float).ravel(), np.asarray(y, float).ravel()
    n, m = len(x), len(y)
    C = np.full((n, m), np.inf)
    C[0, 0] = (x[0] - y[0]) ** 2
    for i in range(1, n):
        C[i, 0] = (x[i] - y[0]) ** 2 + C[i - 1, 0]
    for j in range(1, m):
        C[0, j] = (x[0] - y[j]) ** 2 + C[0, j - 1]
    for i in range(1, n):
        for j in range(1, m):
            cost = (x[i] - y[j]) ** 2
            C[i, j] = cost + min(C[i - 1, j - 1], C[i - 1, j], C[i, j - 1])
    return float(np.sqrt(C[-1, -1])), C

dist, C = dtw([1, 3, 4, 9, 8, 2, 1], [1, 6, 3, 9, 1, 2])
print(f"{dist:.10f}")  # 3.4641016151
print(C[-1, -1])       # 12.0
```

完整路径回溯、Sakoe–Chiba 填格、产线 80／95 对照与出图见 `code/2026-10-28-dtw.py`。

## 局限和要注意的地方

1. **不是度量。** 不宜默认丢进一切依赖三角不等式的几何算法；近邻图、度量学习要另行验证。
2. **病理对齐。** 无窗约束时，一条序列的单个点可能对上另一条的长平台，距离被「摊薄」。工艺上有最大允许扭曲时，应加 Sakoe–Chiba 或 Itakura 平行四边形。
3. **幅度与趋势。** DTW 对纵向尺度敏感；对比前常做 z-score、去基线或只保留包络。未归一就把不同量纲传感器扔进去，数字难解释。
4. **开方约定。** 有的教材直接回报累计和而不开方；与库对表前先确认定义，否则 \(\sqrt{12}\) 会对成 12。
