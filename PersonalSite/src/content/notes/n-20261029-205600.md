## 是什么

**迭代最近点（ICP）** 是一种刚体点云配准算法：给定参考点云（CAD 表面采样、上一帧扫描、数字孪生几何）与待对齐的源点云，交替估计点对应关系与刚体变换 \((R,t)\)，把源点云逐步拧到参考坐标系。Besl & McKay（1992）给出了表示无关的通用框架；Chen & Medioni（1991／1992）同期发展了点到面一类目标。本文演示的是最基础的**点到点**版本：对应点之间的欧氏距离平方和最小。

ICP 不假设事先知道哪一点对哪一点。它只假设：两朵云大致重叠、相对位姿已落在吸引域内（初值不能离谱），以及主要运动是刚体（旋转加平移）。尺度变化、非刚体变形、大比例外点，需要另加预处理或改目标函数；下文外点对照会展示朴素点到点在飞点下的退化。

## 怎么工作

### 直觉画面

把参考点云看成钉在工位上的 CAD 轮廓，扫描点云是同一轮廓被传感器「拧歪」后的采样。每一步先问：扫描里每个点，当前离 CAD 上哪一点最近？得到一批临时对应后，用刚体最小二乘估一把旋转和平移，把整朵扫描云一起挪过去。挪完再重新找最近邻——对应关系会变——再估一把。残差单调下降到几乎不动，或达到最大迭代次数，就停。

最近邻像「暂定配对」，SVD 刚体解像「一次性拧紧所有配对」；二者交替，避免在错误对应上死磕到底。初值太远时，最近邻会系统性对错，算法可能卡在错误局部极小；产线上常用粗配准（特征／多初值／夹具约束）先把位姿送进吸引域。

### 形式定义（挂回直觉）

记参考点集 \(\mathcal{Y}=\{y_j\}\)，当前源点集 \(\mathcal{X}=\{x_i\}\)。一步 ICP 做两件事：

1. **对应**：对每个 \(x_i\)，取 \(y_{(i)}=\arg\min_{y\in\mathcal{Y}}\|x_i-y\|_2\)。
2. **刚体更新**：求

\[
(R^\star,t^\star)=\arg\min_{R\in\mathrm{SO}(d),\,t}\sum_i\|R x_i+t-y_{(i)}\|_2^2,
\]

再用 \(x_i\leftarrow R^\star x_i+t^\star\)。二维／三维都可用质心去中心后的交叉协方差矩阵做 SVD（Kabsch／Arun 型）：\(H=\sum_i (x_i-\bar x)(y_{(i)}-\bar y)^\top\)，\(H=U\Sigma V^\top\)，取 \(R=VU^\top\)（若 \(\det R<0\) 则翻转奇异向量以落在 \(\mathrm{SO}(d)\)），\(t=\bar y-R\bar x\)。

本文 RMSE 定义为源点到参考最近邻距离的均方根：

\[
\mathrm{RMSE}=\sqrt{\frac{1}{N}\sum_i\|x_i-y_{(i)}\|_2^2}.
\]

点到面变体把残差改成到局部切平面的有向距离（Chen & Medioni），在平滑曲面上常收敛更快；Open3D 的 `TransformationEstimationPointToPlane` 即此类。正文数字一律来自自实现的点到点 ICP，不依赖 Open3D 运行时。

### 可核对的小例子

参考云：矩形夹具外轮廓（约 \(6\times 4\)）加一段圆弧与斜撑，合计 **265** 点。真值前向变换：旋转 **28°**、平移 **(3.50, -2.00)**；源云 = 该变换作用于参考后再加 \(\mathcal{N}(0,0.045^2)\) 噪声。要对齐源→参考，真值对齐变换是前向的逆：角 **−28°**，平移约 **(-2.151373, 3.409046)**。

## 复杂度和代价

- **最近邻**：朴素实现每轮 \(O(NM)\)（\(N\) 源点数、\(M\) 参考点数）。本例 \(265\times 265\) 量级，笔记本上瞬时可算。三维稠密扫描常用 kd-tree／体素下采样把查询压到约 \(O(N\log M)\)。
- **SVD 刚体**：固定为 \(O(N)\) 组协方差加 \(2\times 2\) 或 \(3\times 3\) SVD，相对邻域搜索几乎可忽略。
- **迭代次数**：残差在吸引域内常前几轮骤降；本例 **28** 轮到容差。最大迭代、相对 RMSE 变化、对应距离阈值是常见停机条件（Open3D 默认准则同类）。
- **可扩展性**：百万点云先下采样再 ICP，或分层（粗到细）配准；需要全局收敛时配合 FPFH 等特征粗配准多初值。

## 应用场景

- **数字孪生对位**：产线线激光／结构光扫到的工件轮廓，对齐到孪生里的 CAD 或上一合格件，再量间隙、平面度、孔位。
- **工位标定与换型**：夹具或机器人末端扫到的标志几何，相对理论位姿求刚体偏差，写入控制器偏置。
- **多视角拼接**：相邻视角点云两两 ICP，再全局松弛，拼成完整表面。
- **SLAM／里程计后端**：激光帧到局部地图的精配准；初值来自里程计或 IMU。
- **质检**：对齐后做点到面有符号距离场，标红超差区域，而不是在错位坐标系里直接比坐标。

## 实例一：夹具轮廓扫描对 CAD

演示脚本正是这一场景的二维缩影：参考云模拟夹具 CAD 外轮廓与圆弧特征，源云模拟单次扫描的刚体扰动加传感器噪声。对齐后 RMSE 从约 **1.18** 落到约 **0.052**，前向角误差约 **0.14°**，平移分量误差约 **0.01** 量级——在噪声 \(\sigma=0.045\) 设定下，足以支撑「先对齐再量特征」的质检流水线。真实三维扫描还要处理遮挡、密度不均与部分重叠；流程仍是粗初值 → ICP → 残差／内点比例验收。

## 实例二：产线换型后的快速复核

换型后夹具理论位姿写入孪生，首次上线扫描一圈外轮廓。若 ICP 收敛且内点比例、RMSE 落在工艺窗内，则认为「物理夹具与孪生坐标系已锁」；若最终 RMSE 异常偏高而角平移却「看起来合理」，优先排查外点、局部遮挡或非刚体变形（夹具松动），而不是盲目加大迭代次数。点到面 ICP 或截断对应距离，常作为同一工位的下一档稳健化手段；Open3D 文档中的 point-to-plane 教程可直接对照实现差异。

## 短代码（调用核对）

```python
import numpy as np

def estimate_rigid_svd(src, dst):
    mu_s, mu_d = src.mean(0), dst.mean(0)
    H = (src - mu_s).T @ (dst - mu_d)
    U, _, Vt = np.linalg.svd(H)
    R = Vt.T @ U.T
    if np.linalg.det(R) < 0:
        Vt = Vt.copy(); Vt[-1] *= -1
        R = Vt.T @ U.T
    t = mu_d - R @ mu_s
    return R, t

def icp_step(src, target):
    d2 = ((src[:, None, :] - target[None, :, :]) ** 2).sum(2)
    matched = target[d2.argmin(1)]
    return estimate_rigid_svd(src, matched)
```

## 局限和要注意的地方

1. **局部极小。** 初值超出吸引域时，最近邻对应会系统性错乱；对称零件（圆、正多边形）尤其危险。需要粗配准或多初值。
2. **外点敏感。** 上文加 18 个飞点后 RMSE 升到约 **0.41**；生产扫描应先裁剪 ROI、统计滤波，或对对应施距离阈值。
3. **部分重叠。** 源云只覆盖参考一部分时，应对「无可靠对应」的点拒绝更新，否则会被拉向错误区域。
4. **离散采样误差。** 即使变换完美，最近邻落在折线／三角网格顶点上也会留下与点距相关的残差地板；更细的 CAD 采样或点到面可压低该地板。
5. **维度与自由度。** 二维演示 3 自由度；三维刚体是 6 自由度，公式同构，只是旋转用 \(3\times 3\) 正交阵。

## 延伸思考

1. 固定 SEED=42，把噪声标准差从 0.02 扫到 0.12，记录最终 RMSE 与前向角误差，观察残差地板如何随 \(\sigma\) 抬升。

4. 阅读 Open3D ICP 教程中的 fitness／inlier_rmse 定义，把本文 RMSE 与「内点 RMSE」在带阈值设定下对齐口径。
