## 是什么

**二维点集的凸包（convex hull）** 是包住全部输入点的**最小凸多边形**：多边形内部任意两点的连线仍落在多边形内，且再抠掉任何一个顶点就会让某个输入点露到外面。工程上常把它当成「点云的紧外包络」：景观测绘里估场地外轮廓，数字孪生里估工位／传感器占用区，游戏与仿真里做碰撞的粗阶段包围体。

**Andrew 单调链（monotone chain）** 是 A. M. Andrew 1979 年给出的一种 \(O(n\log n)\) 构造法：先把点按横坐标（再按纵坐标）排好序，从左到右建**下凸包**，再从右到左建**上凸包**，两段拼起来就是完整凸包。它和 Graham 扫描同阶，但排序键是笛卡尔坐标而不是极角，实现时少一次「找最低点＋极角比较」，竞赛与库代码里都很常见。

**本文范围：** 静态二维点集、欧氏平面、输出顶点按逆时针排列；共线中间点默认丢掉（叉积 \(\le 0\) 就弹出），只保留严格凸的角。**非范围：** 三维凸包、点动态插入／删除的在线结构、带权或曲线边界的近似包络、以及与凹包（concave hull）／α-shape 的对照——那些是另一套问题。

## 怎么工作

### 直觉画面

把散点按从左到右排成一队。先沿队尾方向「贴着肚子」走一圈下边缘：每加入一个新点，就检查栈顶最近的折线是不是还在「向左转」；若变成右转或走直线，说明上一个点凹进去了（或共线多余），把它弹出，直到重新左转或栈里不够两点。走到最右端后，再从右往左用同一套规则贴上边缘。上下两段在左右端点处相遇，去掉重复端点后拼成一圈。

叉积正负就是「左转／右转」的判决：向量 \(\overrightarrow{OA}\) 与 \(\overrightarrow{OB}\) 的二维叉积

\[
(A_x-O_x)(B_y-O_y)-(A_y-O_y)(B_x-O_x)
\]

大于 0 表示在 \(A\) 处相对 \(O\to A\to B\) 逆时针（左转），小于 0 顺时针，等于 0 共线。单调链在构建时要求保持左转（实现里对 \(\le 0\) 弹出），这样边不会折回去。

### 形式步骤

输入点集 \(P=\{p_0,\ldots,p_{n-1}\}\)：

1. 按 \((x,y)\) 字典序排序，得到 \(p_{(0)},\ldots,p_{(n-1)}\)。
2. **下凸包** \(L\)：从左到右依次压入；当 \(|L|\ge 2\) 且 \(\mathrm{cross}(L_{-2},L_{-1},p)\le 0\) 时弹出 \(L_{-1}\)，再压入 \(p\)。
3. **上凸包** \(U\)：从右到左对同一序列做同样的「保左转」扫描。
4. 输出 \(L\) 去掉最后一个点，再接上 \(U\) 去掉最后一个点（两端点分别与另一段起点重复）。

排序 \(O(n\log n)\)；每个点至多入栈、出栈各一次，两边扫描合计 \(O(n)\)。总时间 \(O(n\log n)\)，额外空间 \(O(h)\)（\(h\) 为壳顶点数，最坏 \(O(n)\)）。

### 可核对的小例子

手工 **8** 个点（与脚本一致）：

| 下标 | 坐标 |
| ---: | --- |
| 0 | \((0.0,\ 0.0)\) |
| 1 | \((1.0,\ 0.2)\) |
| 2 | \((2.0,\ 0.0)\) |
| 3 | \((2.5,\ 1.0)\) |
| 4 | \((1.5,\ 1.5)\) |
| 5 | \((0.5,\ 1.8)\) |
| 6 | \((0.0,\ 1.0)\) |
| 7 | \((1.0,\ 0.8)\) |

排序后原下标顺序为 **`[0, 6, 5, 1, 7, 4, 2, 3]`**。下凸包扫描中弹出 **5** 次，上凸包弹出 **3** 次。最终壳顶点 **h=6**（逆时针）：

\[
(0,0),\ (2,0),\ (2.5,1),\ (1.5,1.5),\ (0.5,1.8),\ (0,1).
\]

内部点是 \((1.0,0.2)\) 与 \((1.0,0.8)\)。鞋带公式面积 **3.35**，轴对齐 bbox 面积 **4.5**，比值约 **0.7444**。

## 复杂度和代价

- **时间：** 主导项是排序 \(O(n\log n)\)；扫描线性。与 Graham 扫描同阶，也是比较模型下的最优量级（输出敏感的更细结果属另一类算法）。
- **空间：** 排序后的点列 \(O(n)\)，壳 \(O(h)\)。
- **数值：** 叉积用浮点时，近共线点可能因舍入在「弹／留」之间抖动；整数坐标可换成 64 位整数叉积。本文演示用 `float`，玩具与场景坐标量级不大，结果可稳定复现。
- **退化：** \(n\le 2\) 时壳就是点本身；全部共线时（丢共线中点策略下）壳退化为两个端点。

## 应用场景

- **景观／测绘边界：** 场地采样、树位点、GPS 桩打完后，先用凸包估「占地外包络」，再和轴对齐矩形比，看角上浪费了多少空白。
- **数字孪生工位包络：** 产线传感器与工装落点求占用凸域，给安全通道、禁入区或相机视野裁剪一个紧一些的多边形，而不是整块外接矩形。
- **碰撞粗检：** Unity／物理引擎里用凸包或由其导出的包围体做宽相位过滤；凹网格往往再拆成凸包集合。
- **计算几何预处理：** 许多算法（旋转卡壳求直径、最远点对、某些可见性查询）以凸包为输入。

凸包吃不准凹进去的港湾与缺口：要贴着真实边界走，需要凹包或多边形化，不在本文范围。

## 实例一：景观测绘场地边界

**SEED=42** 生成不规则场地采样：**n=101**（围栏向桩＋内部测点＋3 个偏外的粗差桩）。单调链得到 **h=8** 个壳顶点。鞋带面积约 **241.8311582618**，全体点的轴对齐 bbox 面积约 **390.7576096270**，

\[
\frac{\text{hull area}}{\text{bbox area}}\approx\mathbf{0.6188776682},
\]

相对矩形浪费约 **38.1%** 的角上空白。演示图中绿线是凸包，灰虚线是 bbox：外壳被少数外点与围栏极值点撑开，内部密点全部落在壳内。

若那 3 个粗差桩是错误 GPS，它们会直接抬高外包络；实务上常先做离群清洗，再求包。脚本保留它们，是为了让「外点进壳」这件事可看见。

## 实例二：产线工位／传感器包络

同一 **SEED=42**（随机流先空转一段，保证与场景 A 点集独立）生成 **n=84** 个工位簇、走廊传感器、标定柱与 1 个偏外信标。壳顶点 **h=6**，面积 **245.375**，bbox 面积 **288.0**，

\[
\frac{\text{hull area}}{\text{bbox area}}\approx\mathbf{0.8519965278},
\]

矩形比凸包多占约 **42.625** 面积单位（约 **14.8%**）。对「整块车间矩形都算占用」的粗模型，换成凸包可以收回边角上的通道与空地；若还要避开凹形过道，需要更高精度的占用多边形。

## 短代码（调用核对）

```python
import numpy as np

def cross(o, a, b):
    return (a[0] - o[0]) * (b[1] - o[1]) - (a[1] - o[1]) * (b[0] - o[0])

def monotone_chain(points):
    pts = np.asarray(points, dtype=float)
    pts = pts[np.lexsort((pts[:, 1], pts[:, 0]))]
    if len(pts) <= 1:
        return pts.copy()
    lower = []
    for p in pts:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in pts[::-1]:
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return np.array(lower[:-1] + upper[:-1], dtype=float)

toy = [(0,0),(1,0.2),(2,0),(2.5,1),(1.5,1.5),(0.5,1.8),(0,1),(1,0.8)]
hull = monotone_chain(toy)
assert len(hull) == 6
assert np.allclose(hull[0], (0.0, 0.0))
assert np.allclose(hull[2], (2.5, 1.0))
```

## 局限和要注意的地方

1. **外点即壳点。** 一个错误坐标就能把整块包络撑大；求包前要有基本的离群处理。
2. **凸不等于贴边。** 场地若有凹湾，凸包会「抄近道」盖住水体或道路，面积偏乐观。
3. **共线策略影响顶点集。** 需要边上的全部桩点时，应改成仅在右转（叉积 \(<0\)）时弹出，并处理好全共线退化。
4. **浮点近共线。** 大规模或大坐标时优先整数叉积或自适应精度。
5. **三维与动态更新** 换算法族（例如随机增量、Gibbs–Chazelle 风格，或维护平衡树的动态凸包），不能直接套本篇二维扫描。
