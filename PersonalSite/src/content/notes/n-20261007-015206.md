数字孪生和产线仿真里，大量工作其实是在回答同一类问题：某台设备、某段工位是不是「还在正常波动范围内」，还是已经开始缓慢偏离。Shewhart 控制图对「一下子跳出去」的大偏移很敏感，但对半个标准差量级的缓慢漂移往往反应迟钝。制造统计过程控制（SPC）里更常用、也更容易落地的一类方法，是 **指数加权移动平均（EWMA）控制图**——对当前观测和历史平滑值做指数加权，再拿平滑后的统计量去比对控制限。它也能套在「预测模型的残差」上：先用健康数据建一个期望输出，再对残差做 EWMA，用来做预测性维护里的早期告警。

本文以 NIST 工程统计手册中的 EWMA 控制图定义为准，顺带说明残差监控的用法，并落到产线与数字孪生场景。

## 是什么

EWMA（Exponentially Weighted Moving Average）最早由 Roberts（1959）引入控制图语境。核心想法很简单：新统计量 = λ × 当前观测 + (1−λ) × 上一时刻的统计量。越久远的数据权重按几何级数衰减，因此「记忆深度」由 λ 决定：

- λ 接近 1：几乎只看最新点，退化为类似 Shewhart 单点图；
- λ 较小（常见 0.05–0.3）：更吃历史，对小而持续的均值漂移更敏感。

Hunter（1986）常被引用的建议是 λ 取 0.2–0.3；NIST 也提到 0.15 很常用。Montgomery 的质量控制教材里，对「专门抓小偏移」的场景会把 λ 推到 0.05–0.25。实践里从 λ=0.2、k=3 起步通常够用。

和 CUSUM 相比，EWMA 实现更直观、参数更少、也更容易和残差流水线拼在一起；和 Isolation Forest 等无监督异常检测比，EWMA 不需要攒大批量特征、可在线逐步更新，解释性更贴近制造 SPC 习惯。选它，是因为它同时覆盖「过程监控」和「预测残差告警」两条落地路径。

## 怎么工作

### 1. 递推定义

记时刻 t 的观测（或子组均值）为 \(Y_t\)，目标/中心线为历史健康数据均值 \(\mu_0\)。令初值 \(Z_0 = \mu_0\)，则：

\[
Z_t = \lambda Y_t + (1-\lambda)\, Z_{t-1},\qquad 0 < \lambda \le 1.
\]

展开后可以看出 \(Z_t\) 是全部历史观测的加权平均，权重为 \(\lambda,\, \lambda(1-\lambda),\, \lambda(1-\lambda)^2,\, \ldots\)，越老越小。

### 2. 方差与控制限

若原始过程近似独立、方差为 \(\sigma^2\)，则 EWMA 统计量的方差随时间变化为：

\[
\mathrm{Var}(Z_t) = \sigma^2 \cdot \frac{\lambda}{2-\lambda}\Bigl[1-(1-\lambda)^{2t}\Bigr].
\]

当 t 较大时，括号内趋近 1，得到常用的**稳态近似**：

\[
\sigma_Z \approx \sigma \sqrt{\frac{\lambda}{2-\lambda}}.
\]

于是上下控制限（NIST 写法，k 常取 2 或 3）为：

\[
\mathrm{UCL} = \mu_0 + k\,\sigma\sqrt{\frac{\lambda}{2-\lambda}},\qquad
\mathrm{LCL} = \mu_0 - k\,\sigma\sqrt{\frac{\lambda}{2-\lambda}}.
\]

若希望启动阶段更严、避免「冷启动假稳」，可用带 \([1-(1-\lambda)^{2t}]\) 的时变限。监控对象是 \(Z_t\) 是否越限，而不是原始 \(Y_t\)——因为 \(Z_t\) 方差更小，控制带也比单点 Shewhart 更窄。

### 3. 残差版（更贴预测性维护）

产线传感器往往随工况（节拍、负载、配方）正常变化，直接对原始读数画 EWMA 容易把「工况切换」误当成异常。更稳妥的做法是：

1. 用健康历史数据建一个期望模型 \(\hat{Y}_t = f(\text{工况},\, \text{时间},\ldots)\)——可以是稳态均值、回归，甚至数字孪生仿真输出；
2. 算残差 \(r_t = Y_t - \hat{Y}_t\)；
3. 对 \(r_t\) 做 EWMA，健康残差均值通常接近 0，\(\sigma\) 用健康残差的标准差估计。

一旦设备缓慢劣化（轴承磨损、滤芯堵塞、温控漂移），残差会持续偏正或偏负，EWMA 会比单点阈值更早越限。

### 复杂度、代价与局限

- **时间/空间**：每点 O(1) 更新，只需存 \(Z_{t-1}\)、\(\mu_0\)、\(\sigma\)、λ、k，极适合边缘网关或数字孪生实时链路。
- **对大跳变**：不如 Shewhart 快；实务上常 **Shewhart + EWMA 联用**（ISO 7870-6 也提到这一点）。
- **假设**：稳态限依赖「健康期」代表性；强自相关、工况剧烈非平稳时，应先建模残差或做差分/标准化，否则误报上升。
- **参数**：λ、k 会权衡检出速度与虚警；应用前建议用历史故障回放调 ARL（平均游程长度）或简单做 ROC 式权衡。

## 应用场景

- 设备振动/温度/电流的缓慢漂移监控；
- 数字孪生里「实机 − 仿真」残差的一致性监控；
- 产线节拍、缓冲库存、通过率等 KPI 的小偏移告警；
- （顺带）股价日收益或波动代理指标的漂移监控——逻辑相同，但金融非平稳更强，只能当辅助信号，不能当交易依据。

## 产线实例

**实例一：主轴电机电流的早期过载趋势。**  
某装配线主轴在正常负载下电流均值约 12.4 A，健康期标准差 σ≈0.35 A。取 λ=0.2、k=3，则

\[
\sigma_Z \approx 0.35\sqrt{0.2/1.8}\approx 0.117,\quad
\mathrm{UCL/LCL}\approx 12.4\pm 0.35.
\]

若刀具逐渐磨损导致电流相对健康均值缓慢抬升 0.4–0.6 A（约 1–1.5σ），Shewhart 单点图可能长期不越 ±3σ，而 EWMA 会在数十个采样周期内越过 UCL，给换刀/检修留窗口。数字孪生侧可用同一套限，把「实机电流 EWMA」与「仿真名义电流」对照，标出逐步偏离的工位。

**实例二：涂装线烘道温度残差监控。**  
烘道设定随配方变化，直接监控绝对温度会频繁误报。先用数字孪生或回归给出 \(\hat{T}_t\)（由设定点、风速、门开闭状态预测），残差 \(r_t=T_t-\hat{T}_t\)。健康残差均值≈0、σ_r≈1.2°C。对 r 做 λ=0.15 的 EWMA：加热器局部失效或热电偶漂移时，残差会出现持续正偏或负偏，EWMA 越限后触发「温控回路体检」，而不是等绝对温度冲出工艺窗口才停线。同一套路可迁到「预测产线拥堵」：用仿真给出期望在制品 WIP，对 WIP 残差做 EWMA，捕捉缓冲槽缓慢堆满的趋势。

## Python 短示例

下面用稳态控制限做最小可运行骨架；C# 侧等价思路是：维护一个 `double z`，每来一个点 `z = lambda * y + (1-lambda) * z`，再和预计算的 `ucl/lcl` 比较即可（`System.Collections` 都不必上）。

```python
import numpy as np

def ewma_control(y, mu0, sigma, lam=0.2, k=3.0, z0=None):
    """对序列 y 做 EWMA 控制图，返回 (z, ucl, lcl, alarms)。"""
    y = np.asarray(y, dtype=float)
    z = np.empty_like(y)
    z_prev = mu0 if z0 is None else z0
    sigma_z = sigma * np.sqrt(lam / (2.0 - lam))
    ucl, lcl = mu0 + k * sigma_z, mu0 - k * sigma_z
    alarms = []
    for t, yt in enumerate(y):
        z_prev = lam * yt + (1.0 - lam) * z_prev
        z[t] = z_prev
        if z_prev > ucl or z_prev < lcl:
            alarms.append(t)
    return z, ucl, lcl, alarms

# 模拟：前 80 点健康 N(12.4, 0.35^2)，后 40 点均值缓慢抬到 12.9
rng = np.random.default_rng(0)
healthy = rng.normal(12.4, 0.35, 80)
drift = rng.normal(12.4, 0.35, 40) + np.linspace(0, 0.5, 40)
y = np.concatenate([healthy, drift])
mu0, sigma = healthy.mean(), healthy.std(ddof=1)
z, ucl, lcl, alarms = ewma_control(y, mu0, sigma, lam=0.2, k=3.0)
print(f"UCL={ucl:.3f}, LCL={lcl:.3f}, first_alarm_index={alarms[0] if alarms else None}")
```

残差版只需把 `y` 换成 `y - y_hat`，并把 `mu0` 设为健康残差均值（常取 0）、`sigma` 设为健康残差标准差。

## 延伸思考

1. 固定 k=3，把 λ 从 0.05 调到 0.5，在你熟悉的一条传感器曲线上观察：首次告警时刻与虚警次数如何变化？  
2. 若采样存在明显自相关（相邻电流强相关），直接套上述公式会怎样？你会先差分、先拟合 AR，还是改做残差 EWMA？  
3. 可对比 **CUSUM**：同样小偏移下，谁的 ARL 更短、谁更难调参；或把 EWMA 接到数字孪生的一条真实（或仿真）KPI 上做回放验证。
