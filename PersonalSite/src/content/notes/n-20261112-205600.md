## 是什么

**Voronoi 图**（也常叫泰森多边形）把平面划成一块块「服务区」：每个站点 \(s_i\) 对应一个单元 \(V(s_i)\)，单元里的点到 \(s_i\) 的欧氏距离不大于到任何其他站点的距离，也就是

\[
V(s_i)=\bigl\{x \bigm| \|x-s_i\|\le \|x-s_j\|\ \text{对所有}\ j\neq i\bigr\}.
\]

相邻两个单元的公共边界落在这两点的**垂直平分线**上。整张图的顶点往往是至少三条边界的交点，它到相关的三个站点等距，也就是这三点外接圆的圆心。气象学里 Alfred H. Thiessen 在 1911 年用这种划分，按雨量站的控制面积做区域平均降雨；计算几何里则把它当作和 Delaunay 三角剖分互为对偶的基本结构。Franz Aurenhammer 1991 年的综述把它称为计算几何中最基本的数据结构之一；Steven Fortune 在 1987 年给出了最坏 \(O(n\log n)\) 时间的扫描线算法。

**本文范围：** 二维欧氏距离、互异点站点、裁到矩形窗口内的单元构造，以及用半平面裁剪实现的可核对演示：玩具五点、车间 8 工位和一场 5 对 5 的最近球员划分。**非范围：** Fortune 扫描线的完整实现、带权或障碍距离、三维 Voronoi、以及把到达时间、加速度和球运行时间纳入的场地控制模型——那些需要单独的算法或数据。

## 怎么工作

### 一个单元是若干半平面的交集

把 \(\|x-s_i\|\le\|x-s_j\|\) 两边平方并整理，得到

\[
(x-m_{ij})\cdot(s_j-s_i)\le 0,
\]

其中 \(m_{ij}=(s_i+s_j)/2\) 是中点。几何含义很直接：过中点作 \(s_i s_j\) 的垂线，留下靠近 \(s_i\) 的那一侧。站点 \(s_i\) 的单元，就是对每一个其他站点做一次这样的半平面截取，再与窗口矩形相交。结果一定是凸多边形；窗口之外原本可能伸向无穷远的单元，会被裁成有限面积，才能谈服务区有多大。

玩具例子里，E 与 A 的中点是 \((3.5,3.5)\)，方向 \(A\to E\) 是 \((3,3)\)，半平面条件化简为 \(x+y\ge 7\)。对 B、C、D 重复同样的步骤，得到另外三条：\(x+y\le 13\)、\(y-x\le 3\)、\(y-x\ge -3\)。四条直线交出的顶点恰好是 \((2,5)\)、\((5,2)\)、\((8,5)\)、\((5,8)\)。这是一个对角线长都为 6 的菱形（其实是旋转 45 度的正方形），面积是 \(6\times 6/2=18\)。角落单元 A 可以看成正方形 \([0,5]\times[0,5]\) 砍掉右上角那个直角边长为 3 的等腰直角三角形：\(25-4.5=20.5\)。B、C、D 由对称得到同样的面积。

下面这段代码只核对查询距离和这两块面积，前提是 Python 3 并能导入 NumPy；预期输出为 `1.414214`、`2.12132 2.12132`、`18.0`、`20.5`。

```python
import numpy as np

A, E = np.array([2.0, 2.0]), np.array([5.0, 5.0])
Q1, Q3 = np.array([3.0, 3.0]), np.array([3.5, 3.5])

def dist(p, q):
    return float(np.linalg.norm(p - q))

print(round(dist(Q1, A), 6))
print(round(dist(Q3, A), 6), round(dist(Q3, E), 6))

diamond = np.array([[2.0, 5.0], [5.0, 2.0], [8.0, 5.0], [5.0, 8.0]])
x, y = diamond[:, 0], diamond[:, 1]
area = 0.5 * abs(np.dot(x, np.roll(y, -1)) - np.dot(y, np.roll(x, -1)))
print(round(float(area), 4))
print(round(25.0 - 0.5 * 3.0 * 3.0, 4))
```

### 用 Sutherland–Hodgman 裁掉远离自己的一侧

实现时不必先求全部直线交点再做点在多边形内测试。对每个站点，先把窗口矩形当作初始多边形，再按其他站点逐条裁。一条半平面裁一个凸多边形，用 Sutherland–Hodgman 规则即可：沿多边形的每条边走，端点都在内侧就留下终点，一侧进一侧出就留下与边界的交点（出到进时还要留下终点）。判断「内侧」的依据正是 \((x-m)\cdot(s_j-s_i)\le 0\)。下面是裁剪的核心；完整的逐站点循环、面积核对与出图见交付包脚本。

```python
import numpy as np

EPS = 1e-12

def clip_halfplane(poly, mid, normal):
    # 保留满足 (x - mid)·normal <= 0 的一侧
    def inside(p):
        return float(np.dot(p - mid, normal)) <= EPS

    def intersect(s, e):
        d = e - s
        t = -float(np.dot(s - mid, normal)) / float(np.dot(d, normal))
        t = min(1.0, max(0.0, t))
        return s + t * d

    out = []
    n = len(poly)
    for i in range(n):
        s, e = poly[i], poly[(i + 1) % n]
        s_in, e_in = inside(s), inside(e)
        if s_in and e_in:
            out.append(e)
        elif s_in and not e_in:
            out.append(intersect(s, e))
        elif (not s_in) and e_in:
            out.append(intersect(s, e))
            out.append(e)
    return np.asarray(out, dtype=float)
```

裁完之后，用鞋带公式求每个单元的面积，全部单元面积之和应当精确等于窗口面积——玩具例子是 100，车间是 \(40\times 24=960\)，球场是 \(105\times 68=7140\)。演示脚本对这三组例子都核对到了 \(10^{-6}\) 以内（车间与玩具为 0，球场残差约 \(4.5\times 10^{-12}\)）。任意落在窗口里的查询点，也应当落在距离最近的那个站点的单元里；若它刚好在公共边上，到两侧站点等距，两侧单元都可以认领。

### 查询其实是最近邻，图给出的是全局剖分

一旦只关心某一个点属于谁，其实不必先构图：直接对全部站点算距离、取最小即可，代价是 \(O(n)\)。Voronoi 图的用处在于把「每一个可能的查询点」一次划清：哪些区域归同一个站点、两个站点的势力在哪条线上交接、哪一块面积最大、拿掉一个站点后面积会流向谁。后一类问题用现成的单元比反复做最近邻扫描更直接。

二维 \(n\) 个互异点的 Voronoi 图，顶点数至多 \(2n-5\)、边数至多 \(3n-6\)（\(n\ge 3\)），平均每个单元的边数小于 6，所以整张图是线性规模。Fortune 的扫描线算法用一条向下扫过平面的线和海滩线（相邻站点的抛物线弧）维护，事件分为站点事件与圆事件，最坏时间 \(O(n\log n)\)，空间 \(O(n)\)，这是比较模型下的最优阶。SciPy 的 `scipy.spatial.Voronoi` 通过 Qhull 计算，得到的是未裁窗口的完整图，无限单元要用窗口再裁一次才能谈面积。本文演示走半平面裁剪，是为了让单元顶点、面积和查询归属都可以逐步核验；站点只有 5、8、10 个，这点额外代价可以忽略。

## 复杂度与代价

- **半平面裁剪：** 对 \(n\) 个站点各裁 \(n-1\) 刀。每一刀处理当前多边形的全部顶点；最坏时单个单元可以有 \(O(n)\) 条边，朴素实现会走到 \(O(n^3)\)。平均边数是常数，常见实现更接近 \(O(n^2)\)。窗口裁剪不会改变渐近阶，但让面积可加。
- **Fortune 扫描线：** \(O(n\log n)\) 时间、\(O(n)\) 空间，适合站点很多、又要精确边和顶点的场合。
- **栅格近似：** 对 \(P\) 个像素各做一次 \(O(n)\) 最近邻，总代价 \(O(Pn)\)。适合出图，不适合当作面积的精确来源——边界像素会带来离散误差。
- **退化：** 四个或更多站点共圆时，一个顶点会关联两条以上的边，浮点相交需要容差。站点几乎重合时，垂直平分线方向不稳定，应当先去重。

## 应用场景

最近站点划分出现在很多「谁负责这块地方」的问题里：雨量站的控制面积、仓库到客户的服务区、传感器或充电桩的覆盖、网格生成里与 Delaunay 三角剖分成对出现。数字孪生车间可以用它估计每个工位的责任地面有多大，以及某一工位停用后负荷会涌向哪些邻居。足球分析里，它是「按最近球员切开球场」的几何底稿；它不管球员的朝向、速度，也不管球要飞多久，所以只能当作场地控制的起点，而不能代替到达时间模型。

### 装配车间的工位服务区

车间窗口是 \(40\,\mathrm{m}\times 24\,\mathrm{m}\)，面积 960 m²。SEED=42、边距 2.5 m、工位最小间距 7 m，抽样得到 8 个工位（单位为米）：

W0 \((29.5885, 10.8387)\)、W1 \((5.7962, 21.0368)\)、W2 \((6.9840, 11.0573)\)、W3 \((15.4779, 20.1085)\)、W4 \((25.0353, 18.1325)\)、W5 \((18.0195, 6.8175)\)、W6 \((36.4744, 19.4693)\)、W7 \((9.4968, 2.6399)\)。

若负荷按面积均分，每个工位应约 120 m²。实际单元面积是 211.4761、85.7318、123.5807、97.2946、107.0123、143.3744、100.4507、91.0793。最大的 W0 占 22.03%，是最小 W1 的 **2.467** 倍。AGV 位于 \((12.40, 9.70)\)，最近工位是 W2，距离 5.5835 m。

假设 W0 故障停用，用剩下 7 个工位重算。W0 原先的 211.4761 m² 只流向几何上与它相邻的三个工位：W4 增加到 155.1353（+48.1230）、W5 增加到 213.9756（+70.6013）、W6 增加到 193.2025（+92.7518）。W1、W2、W3、W7 的面积保持不变，因为它们的单元本来就不和 W0 接壤。新的最大格变成 W5 的 213.9756 m²。AGV 仍归 W2，距离也不变——W0 本来就不是它的最近工位，停用一个不相邻的站点，不会改写它的归属。这张图能回答的是「责任地面怎么重划」，不是「AGV 绕开障碍要走哪条路」；后者仍要在路网或网格上做路径规划。

### 5 对 5 的最近球员划分

球场采用常见的分析尺寸 \(105\,\mathrm{m}\times 68\,\mathrm{m}\)，面积 7140 m²。主队（红，向 \(+x\) 进攻）和客队（蓝）各 5 人，位置写死为：

主队 H-GK \((6,34)\)、H-LB \((36,14)\)、H-CB \((40,34)\)、H-RB \((36,54)\)、H-ST \((72,32)\)；

客队 A-GK \((99,34)\)、A-LB \((74,54)\)、A-CB \((70,36)\)、A-RB \((74,14)\)、A-ST \((28,38)\)。

客队前锋 A-ST 站在主队偏高的防线身后，球在 \((44,36)\)。半平面裁剪得到：主队总面积 **3632.0577** m²（**50.87%**），客队 **3507.9423** m²（**49.13%**），两队几乎对半。但最大的单人单元不是那名插在防线身后的 A-ST（438.6607 m²，占 6.14%），而是靠近边线空当的 H-LB（982.7429 m²，占 13.76%）；主队前锋 H-ST 被客队后卫挤在中间，只剩 331.5657 m²（4.64%），是 10 人里最小的一块。球离 H-CB 最近，距离 \(\sqrt{4^2+2^2}=\sqrt{20}=4.4721\) m。

这个结果说明：按最近球员切开，边路和大禁区附近的空地会划给离得近的人，门将也常常分到一大块本方半场；单元大并不等于更可能接到球，更不等于这段空当有威胁。William Spearman 在 2018 年麻省理工斯隆体育分析会议的论文里，把场地控制建立在到达时间、控球时间和球的飞行时间上，最近距离划分只是一种极限情形。要把图（c）读成「谁能先碰到这个位置上的球」，还缺少速度、朝向和球的轨迹。

## 局限和要注意的地方

1. **欧氏最近不是出行最近。** 车间里有货架和通道时，直线距离上的最近工位，走路网未必最近。球场上速度、加速度和朝向不同，先到达的也不一定是现在离得最近的人。
2. **面积依赖窗口。** 没有裁剪的单元可能伸到无穷远，面积没有定义。窗口改了，靠近边界的单元面积会跟着改，比较负荷时要先固定同一块工作区域。
3. **共圆和重合会让顶点退化。** 四个站点共圆时，两个单元可能在一个点相接而不是在一条边上相接；站点几乎重合时，平分线方向不稳定。
4. **这张图不编码目标价值。** 同样大的单元，在禁区前沿和在己方底线附近的意义完全不同。把面积直接当成控制力或威胁，会把边路空地和门将身后的大块空当高估进去。
5. **半平面裁剪不是大规模下的首选。** 演示里的 \(n\) 很小，核验方便；站点上千时，应改用扫描线或现成的计算几何库，并在窗口上再裁一次。

## 延伸思考

1. 把 E 从 \((5,5)\) 移到 \((5.5,5)\)，重算中心单元的顶点和面积，看 18 与 20.5 的对称性怎样被打破。
2. 在车间例子里改为停用 W5，而不是 W0，记录哪些工位的面积会变，AGV 的归属会不会一起变。
3. 若客队前锋的奔跑速度明显高于后卫，半平面要改成加权距离，边界会离开中点、向较慢的一侧推移；用同一批 5 对 5 坐标比较加权前后 A-ST 的面积。
4. 把共享一条边的站点连起来，得到 Delaunay 三角剖分，检查玩具五点里 E 是否与 A、B、C、D 都相连，以及每个 Voronoi 顶点是否落在某个三角形的外心上。
