## 是什么

主成分分析要回答的问题是：给定一组已经中心化的点，怎样选出新的正交坐标轴，使这些轴依次带走尽可能多的方差。Pearson 在 1901 年把它写成「与点集距离平方和最小的直线或平面」；Hotelling 在 1933 年从另一头给出同一套轴：新变量是原变量的线性组合，彼此不相关，并且方差依次最大。这两种看法对应同一件事：对样本协方差矩阵（或相关矩阵）做特征分解，特征向量给出方向，特征值给出该方向上的方差。

新坐标里的取值叫做得分。若只保留前 \(k\) 个方向，把得分再映回原来的变量空间，就得到这些点在一个 \(k\) 维子空间上的重建；剩下的部分称为残差。残差小，说明点仍落在训练时看见的相关结构里；残差大，说明变量之间的搭配关系和训练期不一致。过程监控里常用两项统计量分开看待这两件事：Hotelling 的 \(T^{2}\) 看得分是否沿保留下来的方向走得太远，SPE（squared prediction error，也称 \(Q\) 统计量）看残差有多大。

**本文范围：** 用样本协方差（分母为 \(n-1\)）做二维可手算的特征分解，并用奇异值分解核对同一组特征值；在量纲不同的四个传感器上，先按训练期的均值和样本标准差标准化，再对相关矩阵做主成分分析；保留第一主成分，用新观测的 \(T^{2}\) 上限和 Jackson–Mudholkar 的 SPE 上限，对照负荷平移与轴承故障。演示里的随机种子是 \(42\)。**非范围：** 核主成分、稳健或稀疏主成分、独立成分分析、因子分析与主成分的模型差别，以及带滞后的动态主成分。文中会提到这些方法针对的问题，但不推导，也不另给实现。控制限采用新观测的常用公式，不用训练样本的经验分位数来改判，后者只作为对照写出。

## 怎么工作

### 中心化之后做样本协方差的特征分解

设数据矩阵 \(X\) 有 \(n\) 行、\(p\) 列，每一行是一次观测。先减去列均值，得到中心化矩阵 \(X_{c}\)。样本协方差是

\[
S=\frac{1}{n-1}X_{c}^{\top}X_{c}.
\]

对 \(S\) 做特征分解 \(S=V\Lambda V^{\top}\)。\(\Lambda\) 的对角元 \(\lambda_{1}\ge\lambda_{2}\ge\cdots\ge\lambda_{p}\ge 0\) 就是各主成分的方差，\(V\) 的第 \(j\) 列是对应的载荷（单位方向）。第 \(i\) 个观测的得分是 \(t_{i}^{\top}=(x_{i}-\bar{x})^{\top}V\)。特征值之和等于 \(S\) 的迹，也等于各原变量的样本方差之和，因此 \(\lambda_{j}/\sum_{m}\lambda_{m}\) 就是第 \(j\) 个成分解释的方差比例。

特征向量的符号可以整体取反，点和轴的相对位置不变。为了和手算对照，下面把每个载荷向量的第一个非零分量都取成正号。

### 中心化矩阵的奇异值分解给出同一组轴

把中心化矩阵写成 \(X_{c}=U\Sigma V^{\top}\)。右侧的 \(V\) 与上面的载荷矩阵是同一组向量（符号约定之后），奇异值与特征值的关系是 \(\lambda_{j}=\sigma_{j}^{2}/(n-1)\)。工程实现里，当 \(n\) 和 \(p\) 一大一小差得较远时，直接对 \(X_{c}\) 做奇异值分解往往比先形成 \(S\) 再特征分解更稳。scikit-learn 的 `PCA` 就是走奇异值分解，并且 `explained_variance_` 同样按 \(n-1\) 来还原方差。

### 四个平面点可以手算完全部中间量

四个点 \((3,\,1)\)、\((1,\,3)\)、\((-3,\,-1)\)、\((-1,\,-3)\) 的均值是原点，\(X_{c}^{\top}X_{c}\) 等于 \(\bigl(\begin{smallmatrix}20&12\\12&20\end{smallmatrix}\bigr)\)，样本协方差因此是

\[
S=\frac{1}{3}\begin{pmatrix}20&12\\12&20\end{pmatrix}=\begin{pmatrix}20/3&4\\4&20/3\end{pmatrix}.
\]

特征方程 \((20/3-\lambda)^{2}-16=0\) 给出 \(\lambda_{1}=32/3\)、\(\lambda_{2}=8/3\)。对应的单位载荷是 \(\bigl(1/\sqrt{2},\,1/\sqrt{2}\bigr)\) 与 \(\bigl(1/\sqrt{2},\,-1/\sqrt{2}\bigr)\)，也就是直线 \(y=x\) 与 \(y=-x\)。第一主成分带走 \(32/40=80\%\) 的方差，第二主成分带走剩下的 \(20\%\)。

点 \((3,\,1)\) 的得分是

\[
t_{1}=3/\sqrt{2}+1/\sqrt{2}=2\sqrt{2},\qquad t_{2}=3/\sqrt{2}-1/\sqrt{2}=\sqrt{2}.
\]

只用第一主成分重建，得到 \(2\sqrt{2}\cdot\bigl(1/\sqrt{2},\,1/\sqrt{2}\bigr)=(2,\,2)\)，残差是 \((1,\,-1)\)，残差平方和是 \(2\)。这个残差恰好等于 \(t_{2}\) 乘第二主成分。两点同在过原点的直线 \(y=x\) 上时，第一主成分就是 Pearson 所说的最近直线；\(y=x\) 到 \((3,\,1)\) 的垂足正是 \((2,\,2)\)。

下面这段代码按同样的约定计算这四个点的特征值和 \((3,\,1)\) 的重建，预期输出是特征值 \(32/3\) 与 \(8/3\)，得分 \(2\sqrt{2}\) 与 \(\sqrt{2}\)，重建 \((2,\,2)\)，残差 \((1,\,-1)\)。

```python
import numpy as np

X = np.array([
    [3.0, 1.0],
    [1.0, 3.0],
    [-3.0, -1.0],
    [-1.0, -3.0],
])
n = X.shape[0]
Xc = X - X.mean(axis=0)
S = (Xc.T @ Xc) / (n - 1)
evals, evecs = np.linalg.eigh(S)
order = np.argsort(evals)[::-1]
evals, evecs = evals[order], evecs[:, order]
# 符号可取反；这里与手算一致，让每个载荷的第一个分量为正。
for j in range(evecs.shape[1]):
    if evecs[0, j] < 0:
        evecs[:, j] *= -1

point = np.array([3.0, 1.0])
scores = point @ evecs
recon = scores[0] * evecs[:, 0]
print(evals)
print(scores)
print(recon)
print(point - recon)
```

同一组中心化数据做奇异值分解，奇异值是 \(4\sqrt{2}\approx 5.6568542495\) 与 \(2\sqrt{2}\approx 2.8284271247\)；各自平方再除以 \(3\)，仍得到 \(32/3\) 与 \(8/3\)。

### 得分是否出界，和残差是否出界，要分开看

保留前 \(k\) 个载荷，记为 \(V_{k}\)，对应的特征值对角阵为 \(\Lambda_{k}\)。对一个已经按训练期规则中心化（必要时还标准化）的新向量 \(z\)，

\[
t=V_{k}^{\top}z,\qquad \hat{z}=V_{k}t,\qquad
\mathrm{SPE}=\lVert z-\hat{z}\rVert^{2},\qquad
T^{2}=t^{\top}\Lambda_{k}^{-1}t.
\]

\(k=1\) 时，\(T^{2}=t_{1}^{2}/\lambda_{1}\)。协方差由 \(n\) 条训练样本估计、再拿来判一条新观测时，常用的 \(99\%\) 上限是

\[
\frac{k(n^{2}-1)}{n(n-k)}F_{0.99}(k,\,n-k).
\]

SPE 的上限采用 Jackson 与 Mudholkar 在 1979 年给出的近似：用未保留特征值的前三阶幂和构造一个变换，再按标准正态分位数反解出上限。这两条限都是近似；下面工位例子里会同时写出训练样本上的经验 \(99\%\) 分位数，供对照，但不改用它们来计数。

## 复杂度与代价

对 \(p\times p\) 的协方差或相关矩阵做特征分解，算术量级是 \(O(p^{3})\)。对 \(n\times p\) 的中心化矩阵做奇异值分解，量级大约是 \(O(\min(np^{2},\,n^{2}p))\)。模型拟合一次之后，一条新观测只需与 \(k\) 个载荷做内积，再算残差，代价是 (O(pk))；本例 \(k=1\)，就是一次长度为 \(p\) 的点积。真正的代价往往不在这一步矩阵分解，而在前面的选择：要不要标准化、保留几个成分、训练段是否真的代表以后的正常工况。\(p\) 接近甚至超过 \(n\) 时，样本协方差会变得很不稳定，这时更该先降维、做正则，或改用专门针对高维的算法，而不是把 \(p\times p\) 的特征值直接当作可靠的方差估计。

## 应用场景

多路传感器一起记录同一台设备时，变量往往高度相关。数字孪生或产线监控可以把正常工况下的相关结构拟合成一个低维平面，再用 \(T^{2}\) 看运行点是否沿这个平面滑得太远，用 SPE 看变量之间的搭配是否还成立。这与逐个传感器设单侧限不同：几个量一起升高，可能只是负荷变了；只有一个量单独偏离共同方向，才更像传感器故障或局部机械损伤。

同一套分解也用在其他相关测量上。例如一组资产收益率的第一主成分，常常接近「大家一起涨跌」的市场方向；若干足球队赛季统计如果高度共线，第一主成分也可以先把「整体强弱」从更细的技战术差异里分开。后面这两种用法本文不另给数字。主成分还可以为后续的回归、分类或可视化提供坐标，但那一步已经超出「找出正交方向并监控残差」本身。

## 装配工位的多传感器监控

演示里的四个量是绕组温度（\({}^{\circ}\mathrm{C}\)）、电机电流（\(\mathrm{A}\)）、振动有效值（\(\mathrm{mm/s}\)）和有功功率（\(\mathrm{kW}\)）。正常工况由一个共同的负荷因子加上彼此独立的小噪声生成，四个量因此一起升降，但单位不同。训练段有 \(400\) 条样本，随机种子是 \(42\)。训练均值是 \((74.947632,\,11.989762,\,1.989366,\,5.492567)\)，样本标准差是 \((3.331425,\,1.141862,\,0.295431,\,0.672773)\)。标准化之后得到的相关矩阵里，温度、电流、功率两两相关约 \(0.985\)，它们与振动的相关约 \(0.953\) 到 \(0.957\)。

相关矩阵的四个特征值是 \(3.911225\)、\(0.060263\)、\(0.014889\)、\(0.013623\)，解释方差比例依次是 \(97.7806\%\)、\(1.5066\%\)、\(0.3722\%\)、\(0.3406\%\)。第一主成分载荷为 \((0.501659,\,0.502006,\,0.494014,\,0.502273)\)，四个传感器几乎均匀出力，方向就是「四个量一起升高或一起降低」。本例只保留这一个成分。按前面的公式，\(n=400\)、\(k=1\) 时系数 \(k(n^{2}-1)/(n(n-k))\) 恰好等于 \(1.0025\)，乘上 \(F_{0.99}(1,\,399)\) 得到 \(T^{2}\) 上限 \(6.715563\)；对应的得分边界是 \(\lvert t_{1}\rvert=\sqrt{\lambda_{1}\cdot 6.715563}=5.125044\)。未保留的三个特征值代入 Jackson–Mudholkar 公式，SPE 上限是 \(0.465043\)。同一批训练样本上，两项统计量的经验 \(99\%\) 分位数分别是 \(6.382603\) 和 \(0.399822\)，参数限略严一些。训练段上 \(T^{2}\) 超限 \(3/400\)，SPE 超限 \(2/400\)。

测试分成三段，标准化仍用训练期的均值和标准差，不再重新估计载荷。正常段 \(150\) 条：\(T^{2}\) 超限 \(4\) 条，SPE 超限 \(0\) 条，\(T^{2}\) 均值 \(1.011222\)，SPE 均值 \(0.096729\)。接着把负荷因子整体上移 \(3.20\)，再生成 \(100\) 条：四个传感器一起升高，\(T^{2}\) 均值升到 \(13.140125\)，超限 \(84\) 条；SPE 均值 \(0.082994\)，超限 \(0\) 条。最后把负荷因子恢复为正常水平，只给振动有效值加上 \(1.00\,\mathrm{mm/s}\)，再生成 \(100\) 条：\(T^{2}\) 均值 \(1.802846\)，超限 \(4\) 条；SPE 均值 \(9.078477\)，\(100\) 条全部超过 \(0.465043\)。

取各测试段下标为 \(50\) 的一条样本，可以把两项统计量算回到原始读数。正常段这条是 \((77.977229,\,12.994833,\,2.227080,\,6.052612)\)，得分 \(1.713691\)，\(T^{2}=0.750848\)，SPE (=0.005429)，都在限内。负荷平移段这条是 \((85.739487,\,15.416354,\,2.809833,\,7.552208)\)，四个量都明显偏高，得分 \(6.041179\)，已经越出 \(5.125044\)，\(T^{2}=9.331052\)，SPE 只有 \(0.088293\)。轴承故障段这条是 \((76.591683,\,12.518142,\,3.247781,\,5.748850)\)，温度、电流和功率仍接近训练中心，振动却到了 \(3.247781\,\mathrm{mm/s}\)；得分 \(2.775494\)，\(T^{2}=1.969553\)，尚未越出得分边界，但标准化残差约为 \((-0.898854,\,-0.930579,\,2.888457,\,-1.013121)\)，SPE (=11.043516)。残差里振动这一项最大，并且温度、电流、功率为负：模型按第一主成分去「解释」偏高的振动时，会预期另外三个量也升高，而它们并没有跟着升，于是残差在两侧同时出现。

若不管相关结构，只按训练期振动的均值 \(1.989366\,\mathrm{mm/s}\) 加 \(2.326348\) 倍样本标准差，得到单侧 \(99\%\) 上限 \(2.676641\,\mathrm{mm/s}\)，则负荷平移段有 \(87/100\) 条超限，轴承故障段有 \(89/100\) 条超限。两段的振动均值分别是 \(2.989426\,\mathrm{mm/s}\) 和 \(3.015897\,\mathrm{mm/s}\)，单看振动几乎一样高。SPE 在平移段一次都没有越限，在故障段全部越限。\(T^{2}\) 和 SPE 合在一起，才能把「沿着平时的相关方向挪了运行点」和「振动不再跟另外三个量同起同落」分开。

正常测试段 \(150\) 条里 \(T^{2}\) 超限 \(4\) 条，略高于名义上的 \(1\%\)。控制限来自正态理论近似，而且负荷因子本身是按正态抽样的；有限样本里出现这样的波动并不奇怪，所以这两条限应当当成约定好的判定门，而不是精确的假警报概率保证。

## 局限

主成分分析只描述线性相关。变量之间若是弯曲的搭配关系，线性平面上的残差会把弯曲和真正的结构破坏混在一起。要不要标准化，会改变轴的方向：量纲不同、方差不可比时，应当先标准化；人为把某一个传感器的尺度放大，它就会在未标准化的协方差里占据过大的权重。训练段里如果已经混进故障或未标明的工况切换，载荷会把这些点也当成「正常结构」的一部分，后面的 SPE 反而可能对同类故障不敏感。\(T^{2}\) 和 SPE 只能发出「这一条不像训练期」的信号，并不能自动指出是哪一个传感器或哪一个物理部件出了问题；贡献图或基于重建的故障识别是后续步骤，本文没有做。观测若有明显的时间相关，把样本当成独立再套 \(F\) 分布或 Jackson–Mudholkar 近似，控制限的含义会偏移。保留几个成分是建模决定：本例第一主成分已经解释 \(97.7806\%\) 的方差，因此只留一个；若正常工况里本来就有第二个可解释的波动源，把它丢进残差，SPE 的上限会被抬高，对小的结构破坏会变钝。

## 延伸思考

选择保留几个成分时，除了看累计方差，还可以对照残差重建误差、平行分析，或把后续监控的假警报与检出能力一起看。Qin 在过程监控综述里比较了基于贡献和基于重建的故障识别，若要在 SPE 报警之后往下追到变量，应当先把识别规则写成与本文监控规则同等明确的步骤，再另做验证。正常波动若含有明显的时间动态，可以把若干滞后项扩进矩阵再做分解，也就是动态主成分；那是另一套预注册，不能把本例的控制限直接搬过去。关系明显非线性时，核主成分或先做非线性特征再分解，会改变「残差」的含义，数字不能与本文的线性 SPE 混着比。
