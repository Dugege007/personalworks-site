# 粒子滤波：用一群假设应对多峰观测与非线性状态估计

产线轨道上的小车测距，在遮挡窗里大约一半回波会偏到真位置右侧约 6 米的「鬼影」峰上；若仍按单峰高斯似然做一维卡尔曼，整段轨迹会被拖偏，演示里全程 RMSE 约 2.00 米。同一段数据上，用 \(N=500\) 个粒子的 SIR（采样重要性重采样）粒子滤波，加权均值估计的 RMSE 约 0.23 米，遮挡窗内更降到约 0.20 米。读完本文可以按 SEED=42 复现脚本，弄清粒子滤波如何用离散样本逼近后验、系统重采样在做什么，以及它和线性高斯卡尔曼在什么观测条件下分道扬镳。

## 是什么

状态估计要回答的问题很具体：在时刻 \(k\)，系统隐状态 \(x_k\)（例如小车沿轨道的位置）不可直接精确得知，只能拿到带噪声、甚至带假峰的观测 \(z_k\)；已知状态如何随时间演化、观测如何依赖状态，希望递推得到后验密度 \(p(x_k\mid z_{1:k})\)，再从中取均值或众数当估计。

线性、噪声高斯时，卡尔曼滤波用均值和协方差就能完整描述后验。非线性或非高斯时，后验往往变成多峰、偏斜，单峰高斯近似会塌到错误的峰上，或在两峰之间「骑墙」。**粒子滤波（particle filter）**，也称**序贯蒙特卡洛（Sequential Monte Carlo, SMC）**，把后验写成一群带权重的样本（粒子）：

\[
p(x_k\mid z_{1:k})\approx\sum_{i=1}^{N} w_k^{(i)}\,\delta\!\left(x_k-x_k^{(i)}\right),
\]

其中 \(\delta\) 是狄拉克点质量，\(w_k^{(i)}\ge 0\) 且 \(\sum_i w_k^{(i)}=1\)。粒子多的地方＝后验认为更可能的区域；权重小的粒子在重采样里会被淘汰。

工程上最常见的一种实现是 **SIR 粒子滤波**（Sampling Importance Resampling），也叫 **bootstrap filter**。Neil J. Gordon、David J. Salmond 与 A. F. M. Smith 在 1993 年 *IEE Proceedings F (Radar and Signal Processing)* 第 140 卷第 2 期（第 107–113 页）的论文 *Novel approach to nonlinear/non-Gaussian Bayesian state estimation* 里提出了该算法，并用仅方位跟踪说明它相对扩展卡尔曼（EKF）的优势。系统教程见 M. Sanjeev Arulampalam、Simon Maskell、Neil Gordon、Tim Clapp 发表于 *IEEE Transactions on Signal Processing* 第 50 卷第 2 期（2002 年 2 月，第 174–188 页）的 *A Tutorial on Particle Filters for Online Nonlinear/Non-Gaussian Bayesian Tracking*：把 SIR、辅助粒子滤波（ASIR）、正则化粒子滤波（RPF）统一写在序贯重要性采样（SIS）框架下，并给出有效样本量与系统重采样的伪代码。

## 怎么工作

### 直觉画面

把每个粒子看成「小车可能在哪」的一个假说。每来一步新测距：

1. **预测**：每个假说按运动模型往前挪一步，并撒一点过程噪声——粒子云跟着扩散。
2. **加权**：看这个假说有多像解释当前观测。落在真回波附近的粒子权重大；落在鬼影峰附近的粒子，若似然里显式包含鬼影模式，也能保住；两边都不像的粒子权重被压扁。
3. **重采样**：按权重有放回地抽 \(N\) 次，权重大的假说被复制多份，权重小的消失；抽完后权重重置为均匀 \(1/N\)。下一轮从这批「幸存假说」再预测。

多峰观测来临时，粒子云可以同时挂在真峰和假峰上；后续若连续几拍更像真峰，质量会逐渐集中回去。卡尔曼只有一个均值、一个方差，被鬼影一拉就整团挪过去，短期很难自觉纠正。

### 形式定义（挂回直觉）

状态与观测的一般模型是

\[
x_k = f(x_{k-1},\,v_{k-1}),\qquad z_k = h(x_k,\,n_k),
\]

其中 \(v\) 是过程噪声，\(n\) 是观测噪声；\(f,h\) 可以非线性，噪声可以非高斯。贝叶斯滤波两步是：

- **预测（Chapman–Kolmogorov）**：\(p(x_k\mid z_{1:k-1})=\int p(x_k\mid x_{k-1})\,p(x_{k-1}\mid z_{1:k-1})\,\mathrm{d}x_{k-1}\)。
- **更新（Bayes）**：\(p(x_k\mid z_{1:k})\propto p(z_k\mid x_k)\,p(x_k\mid z_{1:k-1})\)。

SIR / bootstrap 的具体选择是：重要性密度取**状态转移先验** \(p(x_k\mid x_{k-1}^{(i)})\)，于是权重更新简化为与似然成正比：

\[
\tilde w_k^{(i)} = w_{k-1}^{(i)}\,p(z_k\mid x_k^{(i)}),\qquad
w_k^{(i)}=\tilde w_k^{(i)}\Big/\sum_j\tilde w_k^{(j)}.
\]

每步（或当有效样本量过低时）做重采样。**有效样本量（effective sample size, ESS）**常用估计

\[
\widehat{N}_{\mathrm{eff}}=\Bigl(\sum_{i=1}^{N}\bigl(w_k^{(i)}\bigr)^2\Bigr)^{-1}.
\]

\(\widehat{N}_{\mathrm{eff}}\) 接近 \(N\) 说明权重较均匀；接近 1 说明几乎只剩一个粒子在撑场面（退化）。Arulampalam 等人教程推荐的 **系统重采样（systematic resampling）** 用一条均匀随机起点加等间距扫累积分布，复杂度 \(O(N)\)，蒙特卡洛方差也相对小。

演示里的运动与测距（一维）写成：

\[
x_k = x_{k-1} + v\,\Delta t + \varepsilon_k,\quad \varepsilon_k\sim\mathcal{N}(0,Q),
\]

干净段似然近似 \(\mathcal{N}(x_k, R_{\mathrm{clean}})\)；遮挡窗内显式用「真回波 + 鬼影偏移 \(+6\,\mathrm{m}\)」的混合似然，并始终保留一小部分重尾分量，避免单点离群把全体粒子权重打成数值零。

### 与一维卡尔曼的对照

| 项目 | 一维卡尔曼（演示设定） | SIR 粒子滤波（演示设定） |
|---|---|---|
| 后验形状 | 强制单峰高斯 | 任意（由粒子支撑） |
| 观测模型 | 单一 \(R_{\mathrm{clean}}\) | 混合似然（真峰／鬼影／重尾） |
| 每步存储 | 均值 + 方差 | \(N\) 个位置 + 权重 |
| 典型失效 | 多峰、重尾、强非线性 | 粒子退化、维数高时 \(N\) 爆炸 |

线性高斯且模型对得上时，卡尔曼是最优的，粒子滤波只是更贵的近似；一旦似然多峰或噪声远非高斯，粒子滤波的「多假说」才换来精度。

## 复杂度和代价

- **时间**：每步对 \(N\) 个粒子做传播、似然、归一化；系统重采样 \(O(N)\)。总复杂度约 \(O(TN)\)。演示 \(T=120\)、\(N=500\) 时，粒子滤波约 7 毫秒量级，卡尔曼约 0.04 毫秒量级（同一台解释器、同一次运行）。
- **内存**：\(O(N)\) 浮点；状态维升高时还要乘维数。
- **统计代价**：\(N\) 太小则遮挡窗里可能全军覆没到鬼影；\(N\) 太大则实时性吃紧。ESS 曲线是现场调 \(N\) 与是否每步重采样的仪表盘。
- **工程代价**：似然必须写对。粒子滤波不会「自动发现」鬼影偏移；偏移、混合比例是模型的一部分。维数灾难（curse of dimensionality）下，朴素 SIR 往往不够，需要更好的重要性密度、边缘化或 Rao–Blackwellization。

## 应用场景

- **产线／数字孪生传感器融合**：轨道 AGV、堆垛机、输送线小车的位置估计；激光／超声在立柱、货架间出现多径回波时，单峰滤波易漂。
- **机器人与视觉跟踪**：遮挡后目标重现、背景干扰形成多峰似然（历史上也有 Condensation 等视觉粒子滤波变体）。
- **导航与仅方位／强非线性跟踪**：Gordon 等人 1993 年的动机场景；EKF 线性化不够时粒子滤波更稳。
- **故障诊断与模式切换**：离散模态（正常／打滑／卡滞）与连续状态耦合时，可用混合状态粒子滤波或与卡尔曼分层（Rao–Blackwellized）。
- **金融与计量中的非线性状态空间**：波动率等隐变量的序贯推断（需谨慎处理模型设定与退化）。

## 实例一：一维轨道小车（可复现）

参数写死在脚本里（`SEED=42`）：

- 真速度 \(v=0.45\,\mathrm{m}/\mathrm{step}\)，\(\Delta t=1\)，过程噪声方差 \(Q=0.04\)。
- 干净测距方差 \(R_{\mathrm{clean}}=0.25\)；遮挡窗 \(k\in[40,75]\) 内约 45% 观测落到真位置 \(+6\,\mathrm{m}\) 的鬼影峰（方差 \(0.81\)）；另在 \(k=25,55,90\) 注入大幅离群。
- 粒子数 \(N=500\)，每步系统重采样；对照为假设单一 \(R_{\mathrm{clean}}\) 的一维卡尔曼。
- 时长 \(T=120\) 步。

| 指标 | 卡尔曼 | SIR 粒子滤波 |
|---|---|---|
| 全程 RMSE（米） | \(2.00\) | \(0.23\) |
| 遮挡窗 RMSE（米） | \(3.32\) | \(0.20\) |
| ESS 均值 / 最小 | — | \(408.2\) / \(155.7\) |
| 本机耗时（秒，量级） | \(\sim 4\times 10^{-5}\) | \(\sim 7\times 10^{-3}\) |

演示图上方是真轨迹、散点观测、卡尔曼估计与粒子加权均值；橙色带标出多径／遮挡窗。下方是每步重采样前的 ESS：遮挡段会掉一截，但最小值仍约 156，远高于「只剩一个粒子」的崩溃线。本次仿真中鬼影回波出现 18 次、显式离群 3 次——卡尔曼被这些点系统性拽偏，粒子滤波靠混合似然把质量留在真峰附近。

读表时注意：这不是「粒子滤波永远优于卡尔曼」。若去掉鬼影与离群、只留线性高斯噪声，卡尔曼会更准或至少同样准，而且便宜两个数量级。对照的价值在于钉死：**观测一旦多峰，单峰高斯更新会错在结构上，加粒子数也救不了写错的似然。**

## 实例二：数字孪生里的多传感器融合入口

把同一套 SIR 挂进装配线孪生：小车状态仍是一维里程（或二维平面位姿的位置分量），观测来自「前视激光测距 + 地面磁钉偶发读数」。磁钉干净但稀疏；激光稠密却在货架走廊里周期性出现 \(+d\) 米假峰。孪生侧为激光写混合似然（真距与已知几何鬼影），磁钉用窄高斯；粒子云在走廊段保持双峰警戒，出走廊后磁钉一拍即可把质量打回真峰。若坚持用单一 \(R\) 的卡尔曼，走廊段的位置误差会渗进下游的节拍仿真与碰撞预警，出现「孪生以为车在 A 点、现场车在 B 点」的系统性偏差。扩展时可以把轮速计残差、驱动电流异常做成离散模态，用跳变马尔可夫模型驱动多模型粒子滤波——机制仍是「一群假说 + 按似然存活」。

## 短代码（系统重采样与一步 SIR）

```python
import numpy as np

def systematic_resample(rng, weights):
    n = weights.size
    positions = (rng.random() + np.arange(n)) / n
    return np.searchsorted(np.cumsum(weights), positions, side="right").clip(0, n - 1)

def sir_step(rng, particles, weights, z, process_std, log_likelihood_fn):
    # 预测：按运动模型传播（此处示意为一维加性噪声）
    particles = particles + rng.normal(0.0, process_std, size=particles.size)
    # 更新：权重乘以似然（数值上常用 log-sum-exp，这里用正似然示意）
    like = np.exp(log_likelihood_fn(z, particles))
    weights = weights * like
    weights /= weights.sum()
    estimate = float(np.sum(weights * particles))
    ess = 1.0 / np.sum(weights * weights)
    idx = systematic_resample(rng, weights)
    return particles[idx], np.full_like(weights, 1.0 / weights.size), estimate, ess
```

## 局限和要注意的地方

1. **似然写错等于答案写错。** 粒子滤波不替你发现鬼影偏移；几何多径参数要来自标定或仿真。
2. **退化与贫化。** 每步重采样会降低路径多样性；过程噪声极小时粒子可能塌成一点。可用 ESS 阈值重采样、正则化粒子滤波或 resample-move 等变体缓解。
3. **维数。** 状态维升高时，覆盖后验所需 \(N\) 往往指数级上涨；高维问题优先考虑边缘化线性子空间（Rao–Blackwellized）或更好的提议分布，而不是只加粒子。
4. **实时性。** \(N=500\) 的一维问题很轻；嵌入式多目标跟踪可能要上万粒子或改用专用提议／GPU。
5. **与卡尔曼／无迹卡尔曼的分工。** 近似线性、单峰时，EKF／UKF 通常更划算；粒子滤波留给多峰、强非高斯或离散–连续混合状态。

## 延伸思考

1. 把鬼影偏移从 6 米改成 2 米，观察卡尔曼与粒子滤波的 RMSE 差距如何收窄——峰越近，单峰滤波器越容易「骑墙」却不一定立刻崩。
2. 将 \(N\) 从 50 扫到 2000，画遮挡窗 RMSE 与平均耗时的帕累托曲线，找到你场景可接受的工作点。
3. 把重采样改成「仅当 \(\widehat{N}_{\mathrm{eff}}<N/2\) 时触发」，对比每步重采样的 ESS 轨迹与估计抖动。
4. 若状态扩成 \((位置, 速度)\) 二维，过程噪声只加在速度上，试 Rao–Blackwellized 思路：速度条件线性时对位置用粒子、对速度用卡尔曼，看同样 RMSE 下能否少用粒子。
