# Ramer–Douglas–Peucker 折线简化

公园园路轨迹用 **SEED=42** 采了 **120** 个带噪声样本。容差 **ε=0.15** 时 Ramer–Douglas–Peucker（RDP）把点数压到 **28**（约 **4.29** 倍），原折线每个顶点到简化折线的最大垂距约 **0.145036**；**ε=0.50** 时压到 **7** 点（约 **17.14** 倍），最大垂距约 **0.496344**——两处残差都不超过各自的 ε。读完可以按脚本复现这组数字，弄清「在端点连线上找最远内点，超容差就切开再递归」在砍掉哪些几乎贴线的中间点，以及为什么最大残差被 ε 卡住。

## 是什么

**Ramer–Douglas–Peucker（RDP）** 是一种按容差 ε 抽稀有序折线的算法：输入点列 \(P_0,P_1,\ldots,P_{n-1}\) 与 ε>0，输出仍按原顺序的子集，使被丢掉的点到「保留点连成的折线」的距离不超过 ε。Urs Ramer（1972）与 David Douglas、Thomas Peucker（1973）几乎同时给出同类迭代端点拟合思路；制图、GIS、CAD 与前端地图库里常叫 Douglas–Peucker。

它解决的问题很具体：GPS、激光或手绘采样出来的路径点密、噪声碎，直接画或存会又胖又抖。RDP 不重采样、不拟合曲线，只删「几乎落在当前两端连线上」的中间点，形状由 ε 控制——ε 越大，剩点越少，细节砍得越狠。

## 怎么工作

### 直觉画面

先把整条折线的首尾两点用一根橡皮筋连起来。盯着中间每一个点，量它到这根橡皮筋的垂直距离（投影落到线段外时，改量到较近端点）。距离最大的那个点如果也不超过 ε，说明整段都贴着橡皮筋，中间点全扔，只留两端。若最远点超出 ε，这个点必须留下——它是这段里「最不像直线」的拐弯；然后以它为界，左边一段、右边一段各自再拉橡皮筋、再找最远点，递归做下去，直到每一小段的最远内点都 ≤ ε。

### 形式定义（挂回直觉）

记点列 \(P[0..n-1]\subset\mathbb{R}^2\)，容差 ε>0。点 \(p\) 到线段 \(ab\) 的距离取**有限线段**上的最近点（投影参数 \(t\) 夹到 \([0,1]\)）：

\[
t=\mathrm{clamp}_{[0,1]}\!\left(\frac{(p-a)\cdot(b-a)}{\|b-a\|^2}\right),\qquad
d(p,ab)=\bigl\|p-\bigl(a+t(b-a)\bigr)\bigr\|.
\]

过程 `RDP(i0, i1)`：

1. 在开区间 \((i_0,i_1)\) 内找 \(i^\star=\arg\max_i d(P[i],\,P[i_0]P[i_1])\)，记 \(d_{\max}=d(P[i^\star],\,P[i_0]P[i_1])\)。
2. 若 \(d_{\max}\le\varepsilon\)，只保留下标 \(i_0,i_1\)。
3. 否则保留 \(i^\star\)，返回 `RDP(i0, i★)` 与 `RDP(i★, i1)` 的并（去重端点）。

整条折线从 `RDP(0, n-1)` 起算。被删点相对**最终**简化折线的垂距，按构造不会超过 ε；下文用「每个原点到简化折线各段的最短距离再取最大」打印残差，便于脚本核对。

### 可核对的小例子

设定：6 个点、**ε=0.5**（与脚本 stdout 一致）。

| 下标 | 坐标 |
| --- | --- |
| 0 | (0.00, 0.00) |
| 1 | (1.00, 0.10) |
| 2 | (2.00, 1.00) |
| 3 | (3.00, 0.15) |
| 4 | (4.00, 0.05) |
| 5 | (5.00, 0.00) |

第一轮对端点线段 \(P_0P_5\)（即 \(y=0\) 上的水平段）量垂距：\(d_1=0.10\)，\(d_2=1.00\)，\(d_3=0.15\)，\(d_4=0.05\)。最远点下标 **2**，\(d_{\max}=1.0>0.5\)，保留下标 2 并切开。

- 左段 \(P_0P_2\)：内点只有下标 1，\(d(P_1,P_0P_2)\approx\mathbf{0.357771}\le 0.5\)，丢掉 1。
- 右段 \(P_2P_5\)：\(d(P_3,\cdot)\approx\mathbf{0.490153}\le 0.5\)，\(d(P_4,\cdot)\approx\mathbf{0.268794}\le 0.5\)，丢掉 3 与 4。

最终保留下标 **[0, 2, 5]**。原点列到该简化折线的最大残差 ≈ **0.490153**（恰为被删的 \(P_3\) 到 \(P_2P_5\) 的距离），仍 ≤ ε。

## 复杂度和代价

- **朴素递归**：每一层为找最远点扫一遍当前子段，最坏呈平衡很差的切分，总代价 **O(n²)**；点列近似共线且 ε 较大时往往很快收成两端，平均明显好于最坏。
- **空间**：递归深度最坏 O(n)；可用显式栈改写。本篇演示用朴素递归，点数 120 足够。
- **与均匀抽稀／滑动窗**：等间隔删点不管形状，弯角可能被砍掉；RDP 优先保住偏离端点连线最远的点，弯角与尖点更稳。
- **加速**：凸包预处理、迭代非递归实现、并行分块等可降常数或平均复杂度；GIS 库里常见优化版，语义仍是「ε 容差下的端点拟合」。

## 应用场景

- **景观／园林 CAD**：园路、驳岸、绿篱中心线从测量或手绘进来点很密，出图前按图面比例选 ε 抽稀，既保弯道又减文件体积。
- **GIS 与网页地图**：GeoJSON 折线、等高线、行政边界在缩放级别变化时动态简化，带宽与 GPU 顶点都降下来。
- **数字孪生 AGV／巡检轨迹**：传感器高频采样后，用 RDP 做存储与回放层的有损压缩，ε 对应可接受的路径偏差（米或厘米）。
- **机器人与游戏导航**：导航网格边缘、示教轨迹在进规划器前去掉共线冗余点。
- **触控手写／笔画矢量化**：把密集触点收成少段折线，再交给识别或美化。

## 实例一：景观园路 GPS／CAD 抽稀

SEED=**42** 生成一条带噪声的 S 形园路，**n=120**。坐标系单位可视为米；噪声标准差 0.08，模拟手持 GNSS 或数字化板的小抖动。

| ε | 原点数 | 简化后 | 压缩比 | 最大残差（原→简化折线） |
| ---: | ---: | ---: | ---: | ---: |
| **0.15** | **120** | **28** | **4.285714×** | **0.1450362505** |
| **0.50** | **120** | **7** | **17.142857×** | **0.4963442684** |

ε=0.15 大约允许 15 cm 级偏离，弯道上仍留足折点；ε=0.50 只剩骨架 7 点，适合总平面示意。残差均 ≤ 对应 ε，与算法保证一致。演示图上排两栏分别叠加灰线原轨迹与蓝／红简化折线。

## 实例二：产线 AGV 传感器轨迹

同一 SEED=**42**、同样 **120** 点，换成「两段直行 + 弯角」的车间路径再叠标准差 0.06 的抖动，模拟轮式里程计／二维码校正后的平面轨迹。

| ε | 原点数 | 简化后 | 压缩比 | 最大残差 |
| ---: | ---: | ---: | ---: | ---: |
| **0.15** | **120** | **17** | **7.058824×** | **0.1363746465** |
| **0.50** | **120** | **6** | **20.000000×** | **0.3318363401** |

直行段被大段合并，弯角附近的保留点更密——这正是「最远点优先」相对均匀抽稀的差别。孪生回放或前端地图折线可以用较大 ε 减绘制负担，需要贴地复盘碰撞余量时再换小 ε。演示图左下栏把两种 ε 叠在同一原轨迹上对照。

## 短代码（调用核对）

```python
import numpy as np

def point_segment_distance(p, a, b):
    ab = b - a
    ab2 = float(np.dot(ab, ab))
    if ab2 < 1e-30:
        return float(np.linalg.norm(p - a))
    t = float(np.dot(p - a, ab) / ab2)
    t = max(0.0, min(1.0, t))
    return float(np.linalg.norm(p - (a + t * ab)))

def rdp_indices(points, eps, i0, i1):
    if i1 <= i0 + 1:
        return [i0, i1]
    a, b = points[i0], points[i1]
    dmax, imid = -1.0, i0
    for i in range(i0 + 1, i1):
        d = point_segment_distance(points[i], a, b)
        if d > dmax:
            dmax, imid = d, i
    if dmax <= eps:
        return [i0, i1]
    left = rdp_indices(points, eps, i0, imid)
    right = rdp_indices(points, eps, imid, i1)
    return left[:-1] + right

def rdp(points, eps):
    idx = rdp_indices(points, eps, 0, len(points) - 1)
    return points[idx], idx
```

## 局限和要注意的地方

1. **ε 是几何容差，不是点数配额。** 同样 ε 在平滑路与锯齿路上留下的点数可以差很多；若必须固定输出点数，需要改用「优先队列版」或别的预算约束算法。
2. **只保证相对简化折线的点距 ≤ ε。** 它不最小化 Hausdorff 距离意义下的最优子集，也不保留弧长或曲率积分；自交、拓扑约束要另做检查。
3. **最坏 O(n²)。** 上万点的边界线在交互里可能卡顿，生产环境应换库内优化实现或先分块。
4. **噪声与 ε 同量级时会「保留噪声尖点」。** 园路例里 σ≈0.08、ε=0.15 仍可用；噪声更大时应先平滑或把 ε 提到噪声之上，否则简化结果跟着抖。
5. **三维与带时间戳轨迹。** 经典 RDP 在平面或把坐标当欧氏点；时空轨迹若要保时间，需把时间维纳入距离或做分段约束。

## 延伸思考

1. 固定园路 SEED=42 与 n=120，把 ε 从 0.05 扫到 1.0，画「保留点数–ε」与「最大残差–ε」两条曲线，确认残差曲线不超过 y=ε。
2. 把距离改成「到无限直线」的垂距（不 clamp \(t\)），对比同一 ε 下保留下标是否变化，并解释投影落在端点外时两种定义的差别。
3. 实现 Visvalingam–Whyatt（按三角形面积删点），在同一园路上对照弯角保留与最终点数。
4. 在 Leaflet／Mapbox 的简化工具里找到 Douglas–Peucker 或等价容差参数，用本文 ε 量级估一个屏幕像素容差，看城市边界折线在某一缩放级的观感。
