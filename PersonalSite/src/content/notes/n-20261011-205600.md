# 独立泊松比分模型（Maher 1982）：用攻防强度拆开足球比分概率

足球赛果预测里，比分分布是一条常见建模线。本文只讲 Maher（1982）的**独立泊松比分模型（Independent Poisson score model）**：主队与客队进球各自服从泊松分布，期望进球由攻强、防弱与主场优势相乘得到；整张比分概率矩阵再汇总成胜平负。

## 是什么

Maher, M.J.（1982）《Modelling association football scores》（*Statistica Neerlandica* 36(3), 109–118，DOI 10.1111/j.1467-9574.1982.tb00782.x）重新审视「足球进球能不能用泊松」这件事。更早的工作常把各场进球数混成一池再拟合，发现比泊松更散，于是偏好负二项。Maher 的关键点是：**每场的期望进球本就不该相同**——强攻打弱防，和弱攻打强防，均值差一截；把均值写成「本队攻击 × 对手防守」之后，条件泊松往往已经够用。

论文从参数层级里选出较紧凑的 **Model 2**：每队一套攻击参数与一套防守参数，主客场共用同一套相对强弱，只额外乘一个**全联赛共用的主场因子**。主客进球在主体模型里按**独立**处理。摘要与正文结论的要点是：独立泊松对比分频数的整体拟合尚可；比分差（goal difference）上的偏差更明显；若改用双变量泊松并令相关大约 \(0.2\)，对分差拟合有改进。本文主体仍是独立泊松；Dixon–Coles（1997）对低比分格子的局部修正只放在局限与延伸思考里。

本文采用工程上常见的**乘积参数化**（与 Maher Model 2 等价，只是把原文里的 \(k^2\) 主场缩写拆成可读的 \(\gamma\)，并单独写出联赛基线 \(\tau\)）：

\[
\lambda_{ij}=\tau\cdot\alpha_i\cdot\beta_j\cdot\gamma,\qquad
\mu_{ij}=\tau\cdot\alpha_j\cdot\beta_i
\]

记号约定（全文固定，不要和「防强」混用）：

- \(\alpha_i\)：**攻击强度**。数值大于 \(1\) 表示攻击强于联赛几何均值水平，抬高本队期望进球。
- \(\beta_j\)：**防守薄弱度（defensive weakness）**。数值大于 \(1\) 表示防守偏弱，抬高**对手**期望进球。若你在别的代码里看到「防强」并用除法，那是同一信息的倒数写法，不要两边混写。
- \(\gamma\)：**主场优势因子**（common home advantage）。只乘在主队期望进球 \(\lambda\) 上；\(\gamma>1\) 表示主场多进球。
- \(\tau\)：**联赛进球基线**（baseline expected goals）。控制整体进球尺度；也可以并进 \(\alpha,\beta\) 的标定里，但拆出来读数更直观。
- \(X\sim\mathrm{Poisson}(\lambda)\)：主队进球；\(Y\sim\mathrm{Poisson}(\mu)\)：客队进球；独立时

\[
P(X=x,Y=y)=e^{-\lambda}\frac{\lambda^x}{x!}\cdot e^{-\mu}\frac{\mu^y}{y!}.
\]

对应到 Maher 原文 Model 2：主队均值 \(\alpha_i\beta_j\)、客队均值 \(k^2\alpha_j\beta_i\)。本文的 \(\tau\cdot\gamma\) 扮演原文主场侧尺度，\(\tau\) 扮演客场侧尺度；相对攻防结构相同。

## 怎么工作

### 1. 从攻防参数到 \(\lambda,\mu\)

给定主队 \(i\)、客队 \(j\) 的 \(\alpha,\beta\) 以及全局 \(\gamma,\tau\)，代入上一节公式，得到本场主队期望进球 \(\lambda\)、客队期望进球 \(\mu\)。这不是「预测比分会是几比几」，而是**整张比分分布的两个强度参数**。

### 2. 泊松概率质量函数（Probability Mass Function，PMF）

单边进球为 \(k\) 的概率：

\[
P(K=k)=\mathrm{e}^{-\lambda}\frac{\lambda^k}{k!}\quad(k=0,1,2,\ldots).
\]

独立假设下，比分 \((x,y)\) 的概率就是两边 PMF 的乘积。工程上通常截断到 \(x,y\in\{0,1,\ldots,G\}\)（演示取 \(G=6\)），截断质量接近 \(1\) 时，胜平负可对截断矩阵求和后再按截断内质量归一；也可以先不归一，把尾巴单独记账。演示脚本打印两种。

### 3. 比分矩阵 → 胜平负

令矩阵 \(M_{x,y}=P(X=x,Y=y)\)。则

\[
\begin{aligned}
P(\text{主胜})&=\sum_{x>y}M_{x,y},\\
P(\text{平局})&=\sum_{x=y}M_{x,y},\\
P(\text{客胜})&=\sum_{x<y}M_{x,y}.
\end{aligned}
\]

同一矩阵还能汇总「大小球」「双方是否都进球」等派生盘口；本文只做到胜平负与单个比分格子。

### 4. 小数值逐步演算（与脚本一致）

玩具联赛四队：红杉、青鸟、白鹿、玄铁。固定参数（`SEED=42` 只影响后面合成赛程估参；本场 \(\lambda,\mu\) 由下列常数直接算死）：

| 球队 | \(\alpha\)（攻强） | \(\beta\)（防弱） |
|------|-------------------|------------------|
| 红杉 | \(1.35\) | \(0.85\) |
| 青鸟 | \(1.10\) | \(0.95\) |
| 白鹿 | \(0.95\) | \(1.05\) |
| 玄铁 | \(0.75\) | \(1.20\) |

全局：\(\gamma=1.25\)，\(\tau=1.15\)。焦点场次：**红杉（主）对白鹿（客）**。

\[
\begin{aligned}
\lambda&=1.15\times 1.35\times 1.05\times 1.25=2.03765625,\\
\mu&=1.15\times 0.95\times 0.85=0.928625.
\end{aligned}
\]

算 \(P(1\text{-}0)\)：

\[
\begin{aligned}
P(X=1)&=\mathrm{e}^{-\lambda}\lambda\approx 0.265576,\\
P(Y=0)&=\mathrm{e}^{-\mu}\approx 0.395097,\\
P(1\text{-}0)&=0.265576\times 0.395097\approx 0.104928.
\end{aligned}
\]

在 \(0..6\) 截断矩阵上，脚本给出：

| 比分 | 概率 |
|------|------|
| \(2\text{-}0\) | \(0.106904\)（最高） |
| \(1\text{-}0\) | \(0.104928\) |
| \(2\text{-}1\) | \(0.099273\) |
| \(1\text{-}1\) | \(0.097439\) |
| \(0\text{-}0\) | \(0.051494\) |

截断质量 \(\sum M\approx 0.994943\)。截断内胜平负（未归一）主胜 \(0.625678\)、平 \(0.205956\)、客胜 \(0.163310\)；按截断质量归一后：

\[
P(\text{主})\approx 0.628858,\quad
P(\text{平})\approx 0.207002,\quad
P(\text{客})\approx 0.164140.
\]

对应无抽水公平小数赔率约主 \(1.590\)、平 \(4.831\)、客 \(6.092\)。注意：最高单比分也只有约 \(10.7\%\)。模型给的是**分布**，不是「某场一定 \(2\text{-}0\)」。

## 复杂度／代价

- **已知 \(\lambda,\mu\) 算矩阵**：截断到 \(G\) 时，填 \( (G+1)^2 \) 个格子，每个格子常数时间（或先算两边 PMF 再外积）。\(G=6\) 时只有 \(49\) 格，可忽略。
- **胜平负汇总**：扫一遍矩阵 \(O(G^2)\)。
- **从历史赛果估 \(\alpha,\beta,\gamma\)**：比赛数 \(M\)、球队数 \(n\)。对数似然对每场累加主客两项泊松对数概率；交替迭代或牛顿法常见。每轮大致 \(O(M)\) 量级扫比赛；\(n\) 增大时参数个数约 \(2n+1\)（再加识别约束）。小型联赛笔记本可算；跨季、动态攻防则要时间衰减或状态空间扩展，代价随设计上升。
- **识别约束**：\(\alpha\) 全体乘常数、\(\beta\) 全体除同一常数，乘积不变。现代带基线 \(\tau\)（或对数线性里的 \(c\)）时通常还要再钉一条约束。演示用「\(\alpha\) 的几何均值 \(=1\)、\(\beta\) 的几何均值 \(=1\)」。约束改了，参数数值会变，但拟合出的 \(\lambda,\mu\) 应不变。

## 应用场景

- **足球胜平负／精确比分**：由历史赛果（或你已有的期望进球输入）得到 \(\lambda,\mu\)，展开比分矩阵，再汇总竞彩胜平负、让球、大小球等。它是许多后续模型（Dixon–Coles、双变量泊松、动态攻防）的底座。
- **把「水位隐含概率」和「模型概率」放在同一张表上对照**：水位先去抽水得到隐含胜平负，再与模型输出比差值。本文实例 C 只做对照说明，**不讨论下注策略**。
- **产线／计数类比（一句）**：独立泊松结构本质是「两路离散计数、强度可分解」。产线上若两台设备的故障次数（或单位班次的缺陷件数）在强度上可写成「设备倾向 × 工况负荷」之类乘积，也可以先用同样的「强度分解 → 泊松（或泊松回归）→ 联合格子」思路做粗模型；足球里的主客不对称对应工况不对称。不要硬把胜平负搬进产线。

## 实例 A：给定参数算一场（主演示）

参数与焦点场次见「小数值逐步演算」。结论摘要（与 stdout 一致）：

- \(\lambda\approx 2.0377\)，\(\mu\approx 0.9286\)；
- \(P(1\text{-}0)\approx 0.1049\)；最可能比分 \(2\text{-}0\approx 0.1069\)；
- 归一后胜平负约 \(62.89\%\) / \(20.70\%\) / \(16.41\%\)。

红杉攻强且防不弱（\(\alpha\) 高、\(\beta\) 低），再乘主场 \(\gamma\)，主队期望进球明显高过客队，主胜概率自然抬高；但平局与客胜合计仍超过三成，单比分没有「过半」的确定性。

## 实例 B：合成赛程上的交替极大似然估计（Maximum Likelihood Estimation，MLE）

脚本用**真实参数**按独立泊松抽了双循环×3 的 \(36\) 场合成赛果（`SEED=42`），再用攻击／防守／主场因子交替更新做极简 MLE（几何均值约束）。样本均值主／客进球约 \(1.58\) / \(1.22\)。估出的攻击排序仍是红杉最强、玄铁最弱，但 \(36\) 场噪声大，\(\beta\) 与真值有可见偏差，\(\hat\gamma\approx 1.295\)（真值 \(1.25\)）。用估参回代焦点场，\(\hat\lambda,\hat\mu\) 会漂，胜平负也会漂。这是小样本静态攻防的正常现象，不是实现写错。真联赛要用一整季以上、并加时间衰减或正则。

## 实例 C：模型概率 vs 虚构水位隐含概率（只对照）

虚构小数赔率主 \(1.55\)、平 \(4.20\)、客 \(5.50\)。抽水（overround）约 \(6.51\%\)。\(1/\text{赔率}\) 归一后隐含概率约主 \(60.57\%\)、平 \(22.35\%\)、客 \(17.07\%\)。与实例 A 模型归一结果相比，差值约主 \(+2.31\) 个百分点、平 \(-1.65\)、客 \(-0.66\)。右图并排画出两组柱。这里的水位是假的，差值也只用于演示「如何把两种概率放在同一量纲」；**不构成任何投注建议**。

## 局限与延伸思考

1. **独立假设偏软**：Maher 已指出分差拟合偏差更大；双变量泊松、相关约 \(0.2\) 可改进。真实比赛里先进球会改变节奏（领先方回收、落后方加压），终场 \(X,Y\) 不会严格独立。
2. **低比分系统偏差**：独立泊松常对 \(0\text{-}0\)、\(1\text{-}0\)、\(0\text{-}1\)、\(1\text{-}1\) 等格子不够准。Dixon–Coles（1997）用局部 \(\tau\) 修正这四个格子，并常配合时间衰减权重。这是本文最自然的下一篇扩展。
3. **静态攻防**：转会、伤停、换帅、赛程密度会让 \(\alpha,\beta\) 漂移。需要指数时间衰减、随机游走或卡尔曼式动态强度（可与你已写的卡尔曼／EWMA 思路衔接）。
4. **主场因子共用**：Model 2 假设 \(\gamma\) 对所有队相同；客场远近、草皮、海拔、球迷密度会破坏这一点。
5. **泊松等离散与方差**：条件均值等于方差；若仍有欠／过离散，要负二项或显式混合。
6. **接到现有水位与竞彩数据**：可把历史赛果估出的模型概率，与去抽水后的公司盘／竞彩隐含概率按同一决策时刻对齐做校准与对数损失；注意「禁止跨源升降盘」「按决策时刻取线」一类规则，估参窗口也要避开泄漏。伤停名单、轮换则是特征层问题，不是泊松矩阵本身能发明的。

延伸思考：Dixon–Coles 四个格子的 \(\tau(\rho)\) 怎么写；时间衰减权重如何进似然；双变量泊松共享分量与 \(\rho\approx 0.2\)；把 \(\lambda,\mu\) 改成「期望进球模型输出」再展开矩阵；让球胜平负如何从同一矩阵平移汇总；与水位隐含概率做可靠性图（reliability diagram）而非只看单场差值。
