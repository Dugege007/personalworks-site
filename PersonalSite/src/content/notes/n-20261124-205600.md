巡检车要从朝向 10° 转到朝向 350°，两条朝向在单位圆上的夹角只有 20°。用球面线性插值（Slerp）沿短弧走，参数 \(t=1/4\)、\(1/2\)、\(3/4\) 处的朝向分别是 **5°**、**0°**、**355°**，转过的角度与 \(t\) 成正比。若把 10 与 350 当作普通实数做线性插值，同样三个位置分别是 **95°**、**180°**、**265°**，中点朝向与起点相差 170°，走的是远路。把同一条公式用到单位四元数上：从恒等姿态 \((1,0,0,0)\) 插值到绕 \(Z\) 轴旋转 120° 的 \((1/2,\,0,\,0,\,\sqrt{3}/2)\)，四元数夹角是 60°。\(t=1/3\) 时，Slerp 给出绕 \(Z\) 轴旋转 **40°** 的姿态 \((\cos 20^{\circ},\,0,\,0,\,\sin 20^{\circ})\approx(0.9396926208,\,0,\,0,\,0.3420201433)\)；先线性混合再单位化（Nlerp）得到 \((5\sqrt{7}/14,\,0,\,0,\,\sqrt{21}/14)\approx(0.9449111825,\,0,\,0,\,0.3273268354)\)，转角是 \(2\arctan(\sqrt{3}/5)\approx\)**38.213211°**，角速度并不恒定。单位四元数 \(q\) 与 \(-q\) 表示同一三维姿态：若终点写成 \(-q_1\) 且不做取反，\(t=1/2\) 时姿态变成绕 \(Z\) 轴旋转 **−120°**；取反之后中点是 **+60°**。同一套规则用到 40 m × 24 m 的车间：巡检相机在 \((20.00,\,8.00,\,6.00)\)，先对准工位 A\((8.00,\,8.00,\,1.20)\)，再对准工位 B\((32.00,\,16.00,\,1.20)\)，两条视线的夹角约为 **128.004739°**。\(t=1/2\) 时，Slerp 视线的俯仰是 **−51.614860°**，与工件高度 1.20 m 的平面交于 \((19.029055,\,11.676352,\,1.20)\)；把方位角与俯仰角分别线性插值，中点俯仰是 **−20.104945°**，交点是 \((16.200029,\,20.550453,\,1.20)\)。读完可以按脚本核对朝向短弧的三个分点、120° 旋转在 \(t=1/3\) 的 Slerp 与 Nlerp，以及取反前后的中点姿态。

## 是什么

**球面线性插值**问的是：在单位球面上给出两个点，怎样作一条连接它们的曲线，使得球面上的弧长与参数 \(t\) 成正比。这条曲线就是过这两点与球心的平面截出的大圆弧，也是球面上的测地线。参数均匀变化时，沿弧运动的角速度保持恒定。它的英文缩写 Slerp 来自 spherical linear interpolation。几何公式本身并不依赖四元数，也并不限于三维：两端是单位向量 \(p_0\)、\(p_1\)，夹角 \(\Omega=\arccos(p_0\cdot p_1)\)，则

\[
\operatorname{slerp}(p_0,p_1;t)=\frac{\sin((1-t)\Omega)}{\sin\Omega}\,p_0+\frac{\sin(t\Omega)}{\sin\Omega}\,p_1.
\]

Ken Shoemake 在 1985 年的 SIGGRAPH 论文里，把这条公式用到单位四元数上，用来在三维旋转之间做中间帧。单位四元数可以看成四维空间里的单位球面 \(S^3\) 上的点。球面度量与三维旋转群 \(\mathrm{SO}(3)\) 的角度量一致，因此四元数球面的匀速大圆弧，对应绕一条固定轴、角速度恒定的旋转。四元数夹角为 \(\Omega\) 时，三维转角是 \(2\Omega\)。

单位四元数有双重覆盖：\(q\) 与 \(-q\) 表示同一个三维姿态。大圆弧可以走短的一侧，也可以走长的一侧。若点积 \(q_0\cdot q_1\) 为负，把 \(q_1\) 换成 \(-q_1\)，就可以把 \(\Omega\) 限制在 90° 以内，三维转角不超过 180°。这个取反对方向向量并不成立：视线 \(v\) 与 \(-v\) 指向相反的地方，不能因为点积为负就翻到对面。

**本文范围：** 单位向量与单位四元数上的几何 Slerp；四元数短弧取反只用于姿态，不用于方向；用朝向 10° 到 350° 对照角度线性插值，用绕 \(Z\) 轴 120° 对照 Nlerp 与不取反的远路，再用车间巡检相机对照「沿视线大圆插值」和「方位角与俯仰角分别插值」。演示里的四元数一律按 \((w,x,y,z)\) 书写。**非范围：** 过多个关键姿态的球面三次曲线（Squad）或球面上的 Bézier／de Casteljau 构造，旋转矩阵直接插值，以及用四元数对数与指数映射实现的等价写法 \(q_0(q_0^{-1}q_1)^t\) 的完整推导。文中会提到后一种写法与几何公式等价，但不单独实现。

## 怎么工作

### 几何公式为什么能保持匀速

\(p_0\) 与 \(p_1\) 是单位向量，任何落在它们所张平面里的点都可以写成两者的线性组合。要落在单位球上，而且到 \(p_0\) 的球角正好是 \(t\Omega\)，系数必须取 \(\sin((1-t)\Omega)/\sin\Omega\) 与 \(\sin(t\Omega)/\sin\Omega\)。当两端垂直、\(\Omega=90^{\circ}\) 时，公式退化成熟悉的 \(p_0\cos(t\Omega)+p_1\sin(t\Omega)\)。当 \(\Omega\to 0\) 时，\(\sin((1-t)\Omega)/\sin\Omega\to 1-t\)，公式回到普通线性插值。工程实现里，点积非常接近 1 时，\(\sin\Omega\) 接近 0，直接相除会不稳定；常见做法是改成先线性混合再单位化。Three.js 的 `Quaternion.slerp` 把这个门槛取在点积 0.9995，对应夹角大约 1.81°。

沿这条弧均匀取样，相邻两点之间的球角都等于 \(\Omega\,\Delta t\)。先做线性混合再单位化的 Nlerp 也落在同一段劣弧上，但参数 \(t\) 不再与球角成正比：两端附近转得比较慢，中间比较快。两条路径在端点和在 \(t=1/2\) 处重合，在其他参数上一般会错开。

### 朝向 10° 到 350° 的对照

把巡检车的朝向写成平面单位向量。起点 \((\cos 10^{\circ},\sin 10^{\circ})\)，终点 \((\cos 350^{\circ},\sin 350^{\circ})\)，点积是 \(\cos 20^{\circ}\)，夹角就是 20°。按上面的公式，\(t=1/4\)、\(1/2\)、\(3/4\) 处分别位于弧上 5°、10°、15° 的位置，朝向因此是 5°、0°、355°。把 10 与 350 当实数插值，增量是 340°，三个分点落在 95°、180°、265°。两种算法在端点相同，中点却一个朝前、一个朝后。差来自「把圆上的点当成直线上的数来混合」：350 在实数轴上比 10 大很多，线性插值只能往增大的方向走；在圆上，从 10° 到 350° 的短弧是越过 0° 的那 20°。

方向向量没有「\(v\) 与 \(-v\) 是同一个量」这种等同关系，这里不应做点积取反。本例点积为正，取不取反都不会改变结果。

### 单位四元数：120° 旋转、Nlerp 与短弧取反

约定恒等姿态是 \(q_0=(1,0,0,0)\)。绕 \(Z\) 轴旋转角 \(\alpha\) 的单位四元数是 \((\cos(\alpha/2),\,0,\,0,\,\sin(\alpha/2))\)。终点取 \(\alpha=120^{\circ}\)，于是 \(q_1=(1/2,\,0,\,0,\,\sqrt{3}/2)\)。四元数点积是 \(1/2\)，夹角 \(\Omega=60^{\circ}\)，对应的三维转角正好是 120°。这条路径全部落在 \((w,z)\) 平面的单位圆上，可以手算。

\(t=1/3\) 时，\((1-t)\Omega=40^{\circ}\)、\(t\Omega=20^{\circ}\)，Slerp 的两个系数是 \(\sin 40^{\circ}/\sin 60^{\circ}\) 与 \(\sin 20^{\circ}/\sin 60^{\circ}\)，结果等于 \((\cos 20^{\circ},\,0,\,0,\,\sin 20^{\circ})\)，三维转角是 40°，正好是全程的三分之一。同一参数下的 Nlerp 先得到 \(\frac{2}{3}q_0+\frac{1}{3}q_1=(5/6,\,0,\,0,\,\sqrt{3}/6)\)，欧氏长度是 \(\sqrt{7}/3\)，单位化后是 \((5\sqrt{7}/14,\,0,\,0,\,\sqrt{21}/14)\)，转角 \(2\arctan(\sqrt{3}/5)\approx 38.213211^{\circ}\)，比 40° 少约 1.79°。\(t=1/2\) 时两者都是 \((\sqrt{3}/2,\,0,\,0,\,1/2)\)，转角 60°。\(t=2/3\) 时 Slerp 转 80°，Nlerp 转约 81.786789°。前三分之一里 Nlerp 落后，中间一段它追上来并超过，最后三分之一再放慢——角速度不恒定，但两端和中点与 Slerp 相同。

若把终点写成 \(-q_1=(-1/2,\,0,\,0,\,-\sqrt{3}/2)\)，它与 \(q_1\) 表示同一个三维姿态，四元数点积变成 \(-1/2\)，夹角变成 120°。不做取反时，\(t=1/2\) 的结果是 \((1/2,\,0,\,0,\,-\sqrt{3}/2)\)，对应绕 \(Z\) 轴旋转 −120°：姿态沿着远路走到了另一侧。对 \(-q_1\) 取反之后，路径回到原来的短弧，中点转角是 +60°。Shoemake 的几何论证和后来的实现说明都把「点积为负则取反」当作姿态插值的默认短弧规则。

下面这段代码按几何公式计算 \(t=1/3\) 的 Slerp 与 Nlerp，并打印四元数分量与绕 \(Z\) 轴的转角。前提是 Python 3，只需标准库 `math`。预期输出为四行：Slerp 的分量与 40.0，以及 Nlerp 的分量与约 38.2132107017。

```python
import math

def unit4(q):
    n = math.sqrt(sum(c * c for c in q))
    return tuple(c / n for c in q)

def slerp(q0, q1, t):
    dot = sum(a * b for a, b in zip(q0, q1))
    if dot < 0.0:
        q1 = tuple(-c for c in q1)
        dot = -dot
    if dot > 0.9995:
        return unit4(tuple((1 - t) * a + t * b for a, b in zip(q0, q1)))
    omega = math.acos(min(1.0, max(-1.0, dot)))
    s0 = math.sin((1 - t) * omega) / math.sin(omega)
    s1 = math.sin(t * omega) / math.sin(omega)
    return tuple(s0 * a + s1 * b for a, b in zip(q0, q1))

def nlerp(q0, q1, t):
    dot = sum(a * b for a, b in zip(q0, q1))
    if dot < 0.0:
        q1 = tuple(-c for c in q1)
    return unit4(tuple((1 - t) * a + t * b for a, b in zip(q0, q1)))

def rot_z_deg(q):
    return math.degrees(2.0 * math.atan2(q[3], q[0]))

q0 = (1.0, 0.0, 0.0, 0.0)
q1 = (0.5, 0.0, 0.0, math.sqrt(3.0) / 2.0)
s = slerp(q0, q1, 1.0 / 3.0)
n = nlerp(q0, q1, 1.0 / 3.0)
print(*[f"{c:.10f}" for c in s])
print(rot_z_deg(s))
print(*[f"{c:.10f}" for c in n])
print(rot_z_deg(n))
```

完整的朝向对照、远路取反、车间视线交点与配图见交付包脚本。脚本里对方向向量关闭取反，对单位四元数打开取反，并用上面这些解析值做断言。

## 复杂度与代价

一次 Slerp 只对两个长度固定的向量做点积、一次反余弦、两次正弦和一次线性组合，时间与额外空间都是常数。向量长度在二维、三维或四维之间切换，只改变一个很小的常数因子。两端固定、步长相等时，相邻结果还满足递推 \(p_{k+1}=c\,p_k-p_{k-1}\)，其中 \(c\) 是相邻两点点积的两倍，可以少做一些三角函数，本文演示没有使用这条递推。

Nlerp 少做反余弦和正弦，只做线性混合与一次开方单位化，常数更小，因此在姿态变化很小、或对角速度是否严格恒定不敏感的场合，会被用来代替 Slerp。夹角较大时，Nlerp 在中间段会明显加速，120° 旋转在 \(t=1/3\) 处已经差出约 1.79°。若动画按固定帧间隔播放，并希望转角与时间成正比，应使用 Slerp，或在 \(\Omega\) 接近 0 时再退回 Nlerp。

## 应用场景

三维旋转不能当作三个欧拉角分别插值后再合成，分量线性插值既不能保证角速度恒定，也可能在万向节附近突然改变转动轴。把姿态写成单位四元数再做 Slerp，得到的是绕固定轴的匀速短弧，这正是角色、相机、云台和机器人末端在两个关键姿态之间过渡时常用的做法。Unity 的 `Quaternion.Slerp` 与 Three.js 的 `Quaternion.slerp` / `slerpQuaternions` 都提供了这一操作；Three.js 的实现里，点积为负时对终点取反，点积超过 0.9995 时改走 Nlerp。网页里的相机动画、Unity 里的转向与瞄准、数字孪生里回放设备姿态，用的是同一条公式。平面朝向是二维特例：巡检车、AGV 或玩家角色在地面上转向时，应当在单位圆上沿短弧插值，而不是把角度当作实数来混合。

## 车间巡检相机：大圆路径与方位角–俯仰角分别插值

车间平面是 40 m × 24 m，高度轴朝上。相机在 \((20.00,\,8.00,\,6.00)\)，工件所在平面是 \(z=1.20\)。工位 A 在 \((8.00,\,8.00,\,1.20)\)，工位 B 在 \((32.00,\,16.00,\,1.20)\)。视线起点指向 A，单位向量约是 \((-0.928477,\,0,\,-0.371391)\)，方位角 180°，俯仰约 **−21.801409°**，到 A 的距离是 \(12\sqrt{29}/5\approx 12.924396\) m。视线终点指向 B，单位向量约是 \((0.789474,\,0.526316,\,-0.315789)\)，方位角约 **33.690068°**，俯仰约 **−18.408480°**，到 B 的距离是 15.2 m。两条单位视线的点积约为 −0.615727，夹角约为 **128.004739°**。点积为负只说明夹角大于 90°，仍然小于 180°，短弧就是这一段；视线不是四元数，不能对终点取反，否则相机会改去看相反的方向。

沿这条大圆弧做 Slerp，球角与 \(t\) 成正比：\(t=1/4\)、\(1/2\)、\(3/4\) 处相对起点分别转过约 32.001185°、64.002369°、96.003554°。\(t=1/2\) 时视线俯仰降到 **−51.614860°**，与 \(z=1.20\) 平面交于 \((19.029055,\,11.676352,\,1.20)\)，落在相机南侧不远处。Nlerp 在中点与 Slerp 重合，但在 \(t=1/4\) 时只转过约 18.287800°，俯仰约 −34.712262°，仍然落后于大圆弧上应到的位置。

若把方位角与俯仰角分开、各自做线性插值，方位角沿短弧从 180° 减到约 33.690068°，俯仰从约 −21.801409° 变到约 −18.408480°，几乎一直保持浅俯角。\(t=1/2\) 时方位角约 106.845034°，俯仰约 **−20.104945°**，与同一平面交于 \((16.200029,\,20.550453,\,1.20)\)，更靠近车间北墙。这条路径不是视线上的大圆，角速度也不恒定：中点相对起点的球角约是 67.646198°，不是夹角的一半 64.002369°。

两种结果回答的问题不一样。Slerp 给出视线单位球面的匀速测地线，两个目标方位差得比较开时，短弧会向附近的极点弯曲，所以本例中点会更陡地朝下看。若希望镜头在过渡中保持大致不变的俯仰、只在水平方向扫过车间，应当在方位角的圆上做短弧插值，并单独安排俯仰，而不是对视线方向做 Slerp。数字孪生里回放「相机从 A 扫到 B」之前，需要先确定要保持的是匀速转角，还是近似恒定的俯仰。

## 局限和要注意的地方

Slerp 要求两端已经在单位球上。输入不是单位长度时，应先单位化，否则夹角和系数都会偏。四元数还要先决定 \(q\) 与 \(-q\) 哪一个与起点夹角更小，否则可能在本该走短弧的地方绕远路。两端正好相反、点积等于 −1 时，短弧不唯一，公式里的 \(\sin\Omega\) 也变成 0，需要另行指定旋转轴，本文的例子都避开了这一退化情形。

过三个以上关键姿态时，两两 Slerp 只能保证每一段内部匀速，在节点处的角速度一般不连续。Shoemake 原文后半部分给出的是球面上的样条，后来常用的 Squad 也是为了把多段连接得更顺，这些都不在本文的计算范围里。Slerp 本身也不负责「保持俯仰」或「避开障碍」：车间相机的例子说明，大圆中点可能对着地面，这是球面几何的结果，不是实现错误。

本文四元数按 \((w,x,y,z)\) 书写。Unity 与 Three.js 的接口顺序是 \((x,y,z,w)\)，把分量填错会得到完全不同的旋转。
