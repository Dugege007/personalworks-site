# 卡尔曼滤波（一维）：传感器噪声下的状态估计与一步预测

产线里车还没撞上之前，往往要先把**位置估准**——编码器跳、视觉测距抖，温度／水位传感器也在抖。相对用残差控制图抓漂移的 EWMA，**卡尔曼滤波（Kalman Filter）**是另一条线：显式写状态方程，用协方差把「信模型」和「信观测」算成一个增益 \(K\)，每拍先预测再校正。

## 是什么

经典离散线性卡尔曼滤波，是在**线性动力学 + 高斯白噪声**假设下，对状态做递推最小均方误差估计的一套公式（Kalman 1960；实用入门见 Welch & Bishop）。它同时维护两样东西：

- 状态估计 \(\hat{x}\)（位置、速度、温度……）
- 估计误差协方差 \(P\)（你有多不确定）

每一拍分两段：

1. **时间更新（预测）**：按运动/过程模型把 \(\hat{x}\)、\(P\) 推到下一时刻，得到先验 \(\hat{x}^-\)、\(P^-\)。过程噪声协方差 \(Q\) 在这里把「模型不准」灌进 \(P^-\)。
2. **测量更新（校正）**：拿到观测 \(z\)，用卡尔曼增益 \(K\) 把残差 \(z - H\hat{x}^-\) 融进估计，得到后验 \(\hat{x}\)、\(P\)。观测噪声协方差 \(R\) 越大，越不信传感器。

一维标量（\(A=1\)、\(H=1\)，再加已知控制输入）就能把五步循环讲透；多维把标量换成矩阵即可。过程或观测严重非线性时，在当前估计点线性化得到 **EKF**，或用采样传播均值/协方差得到 **UKF**；二者是适用边界，下文不展开。

和 EWMA 的差别可以记成：EWMA 主要调一个平滑系数 \(\lambda\) 盯残差/均值；卡尔曼多了一层**状态空间**和**协方差递推**，\(K\) 会随 \(P\) 变，冷启动时更信观测、稳态后往往接近某个固定增益。

## 怎么工作

记标量位置状态 \(x\)，已知指令速度 \(v\)、采样周期 \(\Delta t\)。过程与观测：

\[
x_k = x_{k-1} + v\Delta t + w_{k-1},\qquad
z_k = x_k + \eta_k,
\]

其中 \(w\sim\mathcal{N}(0,Q)\)，观测噪声 \(\eta\sim\mathcal{N}(0,R)\)（Welch & Bishop：\(Q\) 过程噪声方差，\(R\) 观测噪声方差；原文常用 \(v_k\) 表观测噪声，这里改成 \(\eta\)，避免和指令速度 \(v\) 撞车）。

### 五步循环（一维）

上一拍结束后手头有后验 \(\hat{x}_{k-1}\)、\(P_{k-1}\)。本拍：

| 步 | 公式 | 含义 |
|---|---|---|
| 1 预测状态 | \(\hat{x}_k^- = \hat{x}_{k-1} + v\Delta t\) | 按指令速度往前推 |
| 2 预测协方差 | \(P_k^- = P_{k-1} + Q\) | 模型不确定，\(P\) 先变大 |
| 3 卡尔曼增益 | \(K_k = P_k^- / (P_k^- + R)\) | \(P^-\) 大 → \(K\) 大 → 更信观测；\(R\) 大 → \(K\) 小 → 更信模型 |
| 4 更新状态 | \(\hat{x}_k = \hat{x}_k^- + K_k(z_k - \hat{x}_k^-)\) | 用残差校正先验 |
| 5 更新协方差 | \(P_k = (1-K_k)P_k^-\) | 融合观测后不确定度下降 |

多维一般式是 \(\hat{x}^-=A\hat{x}+Bu\)，\(P^-=AP A^\top+Q\)，\(K=P^-H^\top(HP^-H^\top+R)^{-1}\)，\(P=(I-KH)P^-\)。一维就是 \(A=H=1\) 的特例。

### \(Q\)、\(R\)、\(K\) 怎么权衡

- **\(R\) 偏大（传感器糙）**：\(K\) 小，滤波轨迹更贴模型，抖得少，但跟不上突变。
- **\(Q\) 偏大（模型不可靠 / 未建模扰动多）**：\(P^-\) 涨得快，\(K\) 偏大，更快跟着观测走，代价是更吃噪声。
- 实践里 \(R\) 常能从标定或厂商规格估；\(Q\) 更像调参旋钮——模型故意写粗一点时，往往要「注」足够的 \(Q\)（Welch & Bishop 也强调这一点）。

### 稳态与指数平滑的直觉

\(Q\)、\(R\) 固定时，\(P\) 和 \(K\) 会很快进入稳态。稳态后再更新，形态接近

\[
\hat{x}_k = (1-K_\infty)\hat{x}_k^- + K_\infty z_k,
\]

也就是**固定增益**的加权平均；若预测就是「上一拍后验」（常值模型），它和指数平滑同一家族。差别在于：卡尔曼在收敛前 \(K\) 会从大变小（先大胆信观测，再稳住），并且预测步可以塞进 \(v\Delta t\) 这类动力学，不是只会「往均值黏」。

## 复杂度与代价

- **一维标量**：每步常数次加减乘除，\(O(1)\)，产线 PLC / 边缘侧可直接跑。
- **状态维 \(n\)、观测维 \(m\)**：主导成本往往是协方差预测里的矩阵乘和增益里的 \(m\times m\) 求逆，粗量级 \(O(n^3)\)（小 \(n\) 时常数更重要）。位置+速度二维、外加一两路测距，实时完全够用。
- 存储只需上一拍的 \(\hat{x}\)、\(P\)，不必攒整段历史——这点和 EWMA 一样适合在线。

## 应用场景

- 数字孪生 / 产线：AGV、堆垛机、传送带工件的位置平滑；把滤波后的 \(\hat{x}\) 和一步预测 \(\hat{x}+v\Delta t\) 送给拥堵/碰撞预判（MAPF 吃的是「估计好的状态」，不是生传感器）。
- 多传感器融合：视觉测距噪声大、编码器漂移慢，可扩成多维 \(H\)、\(R\) 一块融（今天不展开）。
- 温度、压力、液位：过程模型近似「慢变随机游走」时，一维卡尔曼就是带协方差的平滑器。
- 股票收益一步预测：若硬套线性高斯，只能当教学玩具——收益非高斯、波动聚集、跳变常见，严肃场景要用别的模型；非线性观测则考虑 EKF/UKF 或直接换方法。

## 实例 1：AGV 一维位置（走一遍数字）

设定（与脚本一致，`SEED=42`）：

- 指令速度 \(v=1\,\mathrm{m/s}\)，\(\Delta t=1\,\mathrm{s}\)
- \(Q=0.25\)（过程标准差约 \(0.5\,\mathrm{m}\)）
- \(R=4.0\)（观测标准差约 \(2\,\mathrm{m}\)，模拟粗糙视觉/测距）
- 初值 \(\hat{x}_0=0\)，\(P_0=9\)（一开始很不确定）

### 第 1 拍

预测：

\[
\hat{x}^- = 0 + 1\cdot 1 = 1.000,\qquad
P^- = 9 + 0.25 = 9.250.
\]

合成观测 \(z_1=-1.012\)（真值约 \(1.068\)，噪声把读数拽到负的一侧）。

增益与更新：

\[
K = \frac{9.250}{9.250+4} = 0.6981,
\]

\[
\hat{x} = 1.000 + 0.6981\bigl(-1.012 - 1.000\bigr) = -0.404,\qquad
P = (1-0.6981)\cdot 9.250 = 2.792.
\]

解读：初始 \(P\) 很大，\(K\approx 0.70\)，观测权重大；但这一拍 \(z\) 特别差，估计被拽到 \(-0.404\)。\(P\) 从 \(9.25\) 收到 \(2.79\)——不确定度已经明显下降。

### 第 2 拍

预测：

\[
\hat{x}^- = -0.404 + 1 = 0.596,\qquad
P^- = 2.792 + 0.25 = 3.042.
\]

观测 \(z_2=4.117\)（真值约 \(2.236\)）。

\[
K = \frac{3.042}{3.042+4} = 0.4320,
\]

\[
\hat{x} = 0.596 + 0.4320\bigl(4.117 - 0.596\bigr) = 2.117,\qquad
P = (1-0.4320)\cdot 3.042 = 1.728.
\]

\(K\) 已从 \(0.70\) 降到 \(0.43\)：开始少信单次观测。估计 \(2.117\) 贴近真值 \(2.236\)，而裸观测 \(4.117\) 还在乱跳。

### 往后几拍在发生什么

脚本跑 20 步后：\(P\) 收敛到约 \(0.88\)，\(K\) 稳定在约 \(0.22\)；观测 MSE \(\approx 2.44\)，滤波 MSE \(\approx 0.51\)。图里绿线真值、蓝叉观测、红线滤波、紫虚线一步预测——滤波轨迹明显比观测平滑，一步预测就是「当前 \(\hat{x}\) 再加 \(v\Delta t\)」，可直接喂给短时占位/拥堵逻辑。

## 实例 2：温度或股价的一步预测（假设边界）

温度传感器：过程写成 \(x_k=x_{k-1}+w\)（慢变），观测 \(z_k=x_k+\eta\)，上面的五步原样套，\(Q\) 小、\(R\) 按标定。得到的是平滑温度和「下一拍大概还在附近」的先验。

股价：若把收盘价当 \(x\)、设 \(A=1\)、乱填 \(Q/R\)，滤波器仍会吐出一条平滑曲线，但**最优性前提（线性、高斯、噪声独立）几乎不成立**。波动率时变、跳空、肥尾都会破坏 \(P\) 的含义；收益预测更不该默认「卡尔曼一步预测 = 可交易信号」。非线性定价或复杂观测用 EKF/UKF，或直接换 GARCH、状态空间贝叶斯、机器学习；先把假设写进方案，再谈滤波公式。

## 短代码

核心就是预测两行、更新三行：

```python
def kalman_step(x, p, z, v=1.0, dt=1.0, q=0.25, r=4.0):
    x_pred = x + v * dt
    p_pred = p + q
    gain = p_pred / (p_pred + r)
    x_post = x_pred + gain * (z - x_pred)
    p_post = (1.0 - gain) * p_pred
    return x_post, p_post, gain, x_pred, p_pred
```
