120 个二维点里约三分之一是均匀撒开的飞点；对全体做普通最小二乘，斜率从真值 0.70 漂到约 0.48，截距也偏了约 0.16。同一批点上跑 RANSAC（点到直线距离阈值 0.35、最多 200 次迭代，再用共识内点做一次最小二乘精修），斜率回到约 0.71，截距误差约 0.014。读完本文可以按 SEED=42 复现脚本，弄清「假设—检验—扩共识」在做什么，以及离群比例升高时为什么迭代次数会急剧上涨。

## 是什么

模型拟合要回答的问题很具体：给定一组观测点，估计某个参数模型（直线、平面、单应矩阵、刚体位姿……），使模型解释「好」的那部分数据。经典做法是**普通最小二乘（ordinary least squares, OLS）**：对全体残差平方和求最小。它对高斯测量噪声很合适，但遇到**粗差（gross errors）**——分类错了的特征、反射飞点、误匹配——就会被少数离谱点整体拽偏。平方损失没有「拒绝」机制，离群点的残差越大，对参数的拉力越强。

**RANSAC（Random Sample Consensus，随机抽样一致性）**换了一套思路：先用尽量少的点提出一个模型假说，再数有多少点「同意」这个假说（落入误差容限内的点叫**内点 / inliers**，其余叫**外点 / outliers**）；保留内点最多的假说，必要时只用内点再做一次平滑拟合。Martin A. Fischler 与 Robert C. Bolles 在 1981 年 *Communications of the ACM* 第 24 卷第 6 期（第 381–395 页）的论文 *Random Sample Consensus: A Paradigm for Model Fitting with Applications to Image Analysis and Automated Cartography* 里提出该范式，并用于图像分析与自动制图中的定位问题（Location Determination Problem）。原文强调：特征检测器常犯分类错误，这类粗差不会像测量噪声那样被平均掉；RANSAC 的取向与「先用尽量多的点再剔坏点」相反——**先用最小子集，再扩共识集**。

## 怎么工作

### 直觉画面

把拟合直线想成「在一堆钉子里找导轨」：大多数钉子钉在导轨附近，少数钉子被工人随手扔在场地上。

1. **假设**：闭眼随机抽两颗钉子，过它们画一条直线——这就是本轮假说（直线最少要 2 点；圆要 3 点；平面要 3 点；单应矩阵通常要 4 组对应）。
2. **检验**：量每颗钉子到这条直线的垂直距离；距离不超过阈值 \(t\) 的，算「同意」的内点。
3. **记分**：内点越多，假说越好。重复许多轮，留下内点最多的那条。
4. **精修（常用）**：只用最终共识内点再做一次最小二乘，把噪声平均掉；可选地用精修后的模型重新划定内点。

普通最小二乘相当于「强迫所有钉子都上导轨」；RANSAC 先问「有没有一条导轨能解释大多数钉子」，再在同意者里精修。

### 形式定义（挂回直觉）

设数据为 \(\mathcal{D}=\{(x_i,y_i)\}_{i=1}^{n}\)，模型为直线 \(y=ax+b\)。点到直线的垂直距离是

\[
d_i(a,b)=\frac{|a x_i - y_i + b|}{\sqrt{a^2+1}}.
\]

给定阈值 \(t\)，共识集（内点集）为

\[
\mathcal{I}(a,b)=\bigl\{i:\; d_i(a,b)\le t\bigr\}.
\]

经典 RANSAC 循环：

1. 均匀随机抽最小样本（此处 \(s=2\) 个不重复点），由两点解析出 \((a,b)\)；若两点 \(x\) 几乎重合导致竖直直线，则本轮跳过（演示模型是 \(y=ax+b\)，不含竖直情形）。
2. 对全体点算 \(d_i\)，得到 \(|\mathcal{I}|\)。
3. 若当前 \(|\mathcal{I}|\) 优于历史最佳，则更新最佳假说与共识集。
4. 重复至预定迭代次数 \(N\)（或达到自适应停止条件）。

最终常用 \(\hat a,\hat b=\arg\min_{a,b}\sum_{i\in\mathcal{I}}(y_i-ax_i-b)^2\) 在共识集上精修。

迭代次数与「至少抽到一次纯内点样本」的成功率相关。设内点比例为 \(w\)，最小样本大小为 \(s\)，希望以概率至少 \(p\) 抽到至少一次全是内点的样本，则所需迭代数约为

\[
N \ge \frac{\log(1-p)}{\log\!\bigl(1-w^{s}\bigr)}.
\]

白话翻译：\(w^{s}\) 是「一次就抽中 \(s\) 个全内点」的概率；\(1-w^{s}\) 是单轮失败概率；要把失败概率压到 \(1-p\) 以下，就得重复足够多轮。\(w\) 变小或 \(s\) 变大时，\(w^{s}\) 掉得很快，\(N\) 会急剧上升——这就是离群比例高、模型又「胃口大」（样本点多）时 RANSAC 变贵的原因。

### 可核对的小例子（演示设定）

真直线 \(y=0.7x+1.2\)。在 \(x\in[-5,5]\) 上生成 80 个内点，叠加 \(\mathcal{N}(0,0.15^2)\) 噪声；再加 40 个 \(y\) 在 \([-8,12]\) 均匀分布的飞点。内点比例 \(w\approx 80/120\approx 0.667\)。取 \(p=0.99\)、\(s=2\)：

\[
N \ge \frac{\log(0.01)}{\log(1-0.667^{2})}\approx 8.
\]

理论下限大约只要十几轮量级；演示写死 \(N=200\)、\(t=0.35\)，给随机波动留余量，并与工程里「宁可多抽几轮」的习惯一致。若把 \(w\) 降到 0.3 而仍取 \(s=2\)，同样 \(p=0.99\) 时 \(N\) 约升到 50 量级；若拟合平面 \(s=3\) 且 \(w=0.3\)，\(N\) 可到一两百——样本稍大、飞点稍多，算力就上去了。

## 复杂度和代价

- **时间**：每轮代价 ≈ 拟合最小样本 \(O(s)\) + 检验全体点 \(O(n)\)（直线距离是常数时间）。总复杂度约 \(O(N\cdot n)\)，外加最后一次内点最小二乘 \(O(|\mathcal{I}|)\)。演示 \(n=120\)、\(N=200\) 在普通解释器上是毫秒级。
- **成功概率 vs 代价**：上面的公式说明，离群比例从 30% 升到 70%（\(w\) 从 0.7 降到 0.3）时，同样 \(s\) 下 \(N\) 可涨一个数量级；模型从直线（\(s=2\)）换到单应（\(s=4\)）再叠加低 \(w\)，迭代需求会爆炸。实践中常用自适应 \(N\)：边跑边按当前最佳 \(w\) 估计上调或提前停。
- **阈值 \(t\)**：太紧会把噪声内点判成外点；太松会把飞点吞进共识集，精修时再度被污染。\(t\) 应贴近测量噪声尺度（演示噪声标准差 0.15，阈值取 0.35，约两倍多一点的垂直容限）。
- **退化样本**：共线重复点、近重点、数值病态的最小求解会导致假说无效，实现里要跳过或加约束。
- **不是万能鲁棒器**：多结构（两条交叉直线、两个平面）时，标准 RANSAC 倾向吃掉最大结构；需要顺序剥除、多模型或更专门的变体。

## 应用场景

- **产线／数字孪生点云标定**：激光或结构光扫地面、工作台、导轨时，常混入立柱回波、人员遮挡、灰尘飞点。用 RANSAC 拟合平面或直线，先拿共识内点定坐标系，再谈下游节拍与干涉检查。
- **传感器回归去污染**：温度—形变、电流—扭矩等标定曲线若被偶发通讯错帧或传感器饱和污染，最小二乘斜率会漂；RANSAC 可先隔离飞点再精修。
- **装配位姿与视觉几何**：点云到 CAD 的粗配准、图像直线／圆检测、特征匹配后的单应或本质矩阵估计，经典流水线几乎都是「匹配 + RANSAC 剔误匹配」。
- **旁例（非主场景）**：股票因子回归或足球指标拟合里若混入停牌日、录入错值，也可把 RANSAC 当「带脏点的回归」预处理器；主战场仍是几何与传感器标定。

## 实例二：产线点云地面／导轨标定入口

把同一套路接到装配工位孪生：头顶激光雷达一帧点云里，地面点占多数，货架腿、托盘边、走过的人形成离群。对「平面」模型取 \(s=3\)，距离阈值按传感器噪声与安装抖动标定（例如数毫米到一两厘米）。RANSAC 先给出地面法向与高度，把地面内点抠出来做高度基准；再在剩余点里对导轨或传送带边缘跑一次直线 RANSAC，得到平面内的导向轴。下游的 AGV 定位与碰撞体生成只信任共识内点，避免「孪生地面被一根立柱拽歪」导致整条线的高度误差。若离群比例临时升高（粉尘、焊接飞溅），按公式把 \(N\) 加大或改用局部采样，而不是先信最小二乘再靠人工删点。

## 短代码（两点假说 + 距离检验）

```python
import numpy as np

def point_line_distances(x, y, a, b):
    return np.abs(a * x - y + b) / np.sqrt(a * a + 1.0)

def ransac_line(x, y, rng, thresh=0.35, max_iters=200):
    n = x.size
    best_mask = np.zeros(n, dtype=bool)
    best_count = -1
    for _ in range(max_iters):
        i, j = rng.choice(n, size=2, replace=False)
        if abs(x[j] - x[i]) < 1e-12:
            continue
        a = (y[j] - y[i]) / (x[j] - x[i])
        b = y[i] - a * x[i]
        mask = point_line_distances(x, y, a, b) <= thresh
        if mask.sum() > best_count:
            best_count = int(mask.sum())
            best_mask = mask
    a, b = np.polyfit(x[best_mask], y[best_mask], 1)  # 内点精修
    return float(a), float(b), best_mask
```

## 局限和要注意的地方

1. **阈值与噪声绑在一起。** \(t\) 不是万能旋钮；噪声方差变了要重标定，否则内点集会胀或瘪。
2. **单结构假设。** 场景里若同时存在两条近乎等势的直线，标准 RANSAC 通常只稳定吃住较大的那条。
3. **最小样本的退化。** 近重点、重复点会产生不稳定假说；实现必须显式拒绝。
4. **精修仍可能吃进边界外点。** 阈值边缘的飞点若被算进共识集，最后一次最小二乘仍会轻偏；可用更严的二次阈值或 M-estimator 精修。
5. **与稳健回归的分工。** Huber、Tukey 等连续降权方法在中等污染下往往更稳、更省随机性；粗差比例很高、又存在明确几何最小样本时，RANSAC 更直接。

## 延伸思考

1. 把飞点比例从 \(40/120\) 扫到 \(80/120\)，固定 \(N=200\)，观察 RANSAC 参数误差何时开始崩溃，并对照公式给出的 \(N(w)\) 是否该上调。
2. 将阈值从 \(0.2\) 扫到 \(0.8\)，画召回、精度与 \(\lvert\hat a-a_{\mathrm{true}}\rvert\) 的曲线，找你噪声尺度下的工作点。
3. 去掉「内点再最小二乘」精修，只比较最佳两点假说与精修后的误差，量化平滑步骤的贡献。
4. 把模型改成圆（\(s=3\)）或三维平面，用同一套「假设—检验—精修」骨架，核对 \(N\) 公式里 \(s\) 升高带来的迭代膨胀。
